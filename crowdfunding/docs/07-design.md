# 07. デザインシステム仕様

購入型クラウドファンディングのプラットフォーム。白基調・カード主役・万人向け。

**この文書が唯一の真実。** 実装で迷ったらここに戻る。ここに書いていない値を勝手に足さない。
視覚的な確認は [../design/styleguide.html](../design/styleguide.html) をブラウザで開く（ビルド不要）。

---

## 0. このプロダクトのデザインが背負っているもの

クラウドファンディングの UI は、突き詰めると **3つのこと**しかしていない。

| | 問い | UI が答える手段 |
|---|---|---|
| 1 | **信用できるか** | 出品者の実在感、実績、運営の審査、情報の整合性 |
| 2 | **いくら集まっているか** | 金額・達成率・支援者数・残り時間 |
| 3 | **いま支援すべきか** | 締切、在庫、達成の近さ、CTA の到達しやすさ |

だからこのシステムの設計判断は、ほぼすべて次の3原則から導出される。

### 原則1 — 金額が主役

**ページ内で最も強い視覚的重みは、常に金額**。見出しでもロゴでもない。
金額には必ず等幅数字（`tabular-nums`）を当て、桁を揃える。揃っていない金額の一覧は、それだけで素人臭くなる。

### 原則2 — アクセントは1色、使い道は2つだけ

アクセント（`accent/600`）を使ってよいのは **支援 CTA** と **進捗バー** のみ。
それ以外に使うと、ページ内で最も重要なボタンが埋もれる。

ステータス色（成功・警告・危険）はアクセントとは別の役割で、**状態を伝えるためだけ**に使う。装飾に使わない。

### 原則3 — 空白は削らない

情報量が多いサービスほど、詰めると安っぽくなる。カード間・セクション間の余白は削らない。
削るべきは要素の数であって、余白ではない。

## 1. カラー

### 1.1 プリミティブ（原色）

**この値を直接 CSS に書かない。** 必ず §1.2 のセマンティックトークン経由で参照する。
色を変えるときはここだけを触る。

#### Neutral — わずかに寒色に振ったグレー

純粋なグレー（`#808080` 系）は「何も考えていない」色に見える。
青緑側にわずかに寄せることで、アクセントの赤と補色関係になり、白基調が締まる。

| Token | Hex | 白背景とのコントラスト | 用途 |
|---|---|---:|---|
| `neutral/0` | `#ffffff` | — | ページ地・カード地 |
| `neutral/50` | `#f6f8fa` | 1.05 | セクション地・沈んだ面 |
| `neutral/100` | `#eef1f5` | 1.10 | 進捗バーの溝・スケルトン |
| `neutral/200` | `#e2e7ee` | 1.24 | 境界線（既定） |
| `neutral/300` | `#cbd3de` | 1.51 | 境界線（強）・区切り |
| `neutral/400` | `#9aa5b5` | 2.49 | 無効状態・プレースホルダ |
| `neutral/500` | `#6b7688` | **4.59** | 補助テキスト ✅AA |
| `neutral/700` | `#3d4552` | **9.67** | 本文 ✅AAA |
| `neutral/900` | `#161a21` | **17.44** | 見出し・金額 ✅AAA |

#### Accent — コーラルレッド

| Token | Hex | 白とのコントラスト | 用途 |
|---|---|---:|---|
| `accent/50` | `#fff2f0` | 1.04 | バッジ地・淡い強調 |
| `accent/100` | `#ffe1dd` | 1.15 | 選択中のカード地 |
| `accent/500` | `#f04a38` | 3.66 | 図形のみ（文字に使わない） |
| `accent/600` | `#dc3520` | **4.59** | **CTA 塗り・進捗バー** ✅AA |
| `accent/700` | `#b82717` | **6.29** | ホバー・アクセント文字 ✅AA |
| `accent/800` | `#961f13` | 8.4 | 押下時 |

> **`accent/600` を選んだ理由。** 明るいコーラル（`#ff5a4d` 等）は白背景で 3.1:1 しかなく、
> **文字色として使えない**。600 まで深めることで 4.59:1 となり、塗りボタンの白文字・
> 白背景上のリンク文字の**両方**で AA を満たす。1色で全用途をまかなえるのは大きい。

#### Status

| 役割 | 淡色地 | 濃色（文字・アイコン） | 淡色地上のコントラスト |
|---|---|---|---:|
| Success | `#e9f7f0` | `#0a6543` | **6.44** ✅ |
| Warning | `#fff6e6` | `#7f5100` | **6.36** ✅ |
| Danger | `#fdeceb` | `#9c1a1a` | **7.13** ✅ |
| Info | `#eaf2fd` | `#164e9b` | **7.17** ✅ |

### 1.2 セマンティックトークン

実装はこの名前だけを使う。**ダークモードを将来足すときも、ここの値を差し替えるだけで済む。**

```css
:root {
  /* 面 */
  --surface-page:     #ffffff;   /* ページ地 */
  --surface-sunken:   #f6f8fa;   /* 沈んだ面。セクション背景 */
  --surface-raised:   #ffffff;   /* 浮いた面。カード */
  --surface-inset:    #eef1f5;   /* 窪んだ面。進捗の溝・スケルトン */
  --surface-overlay:  rgb(12 15 20 / 0.55);

  /* 境界 */
  --border-subtle:    #e2e7ee;   /* 既定。カード枠 */
  --border-default:   #cbd3de;   /* 入力欄・セカンダリボタン */
  --border-strong:    #9aa5b5;   /* ホバー時 */

  /* 文字 */
  --text-primary:     #161a21;   /* 見出し・金額 */
  --text-secondary:   #3d4552;   /* 本文 */
  --text-tertiary:    #6b7688;   /* 補助・メタ情報 */
  --text-disabled:    #9aa5b5;   /* 無効。文字として使うのは最小限に */
  --text-inverse:     #ffffff;
  --text-link:        #b82717;   /* 本文中のリンク。必ず下線を併用 */

  /* アクセント */
  --accent-bg-subtle: #fff2f0;
  --accent-bg-muted:  #ffe1dd;
  --accent-solid:     #dc3520;   /* CTA 塗り・進捗バー */
  --accent-solid-hover:  #b82717;
  --accent-solid-active: #961f13;
  --accent-text:      #b82717;
  --on-accent:        #ffffff;

  /* 状態 */
  --success-bg: #e9f7f0;  --success-fg: #0a6543;  --success-solid: #0d7f53;
  --warning-bg: #fff6e6;  --warning-fg: #7f5100;  --warning-solid: #a06600;
  --danger-bg:  #fdeceb;  --danger-fg:  #9c1a1a;  --danger-solid:  #c02020;
  --info-bg:    #eaf2fd;  --info-fg:    #164e9b;  --info-solid:    #1a5fbf;

  /* フォーカス */
  --focus-ring: #dc3520;
}
```

### 1.3 使ってはいけない組み合わせ

| ✕ | 理由 |
|---|---|
| `accent/500` 以下を文字色に | 白背景で 3.66:1。AA 未満 |
| `neutral/400` を本文に | 2.49:1。無効状態の表現にのみ使う |
| アクセントを見出し・アイコン・区切り線に | CTA が埋もれる |
| ステータス色を装飾に | 「意味がある色」であることが伝わらなくなる |
| 色だけで情報を伝える | 「残りわずか」は色＋文言の両方で示す |

### 1.4 ダークモード

**v1 では実装しない。** 工数に対して効果が薄い。

ただし上記のとおり**セマンティックトークンで抽象化してあるので、後から足せる**。
実装するときは `:root` の値を上書きするだけで、コンポーネント側は一切触らない。
コンポーネントの CSS に生の hex を書いた時点でこれが壊れるので、**必ずトークン経由で書く**。

## 2. タイポグラフィ

### 2.1 Web フォントを読み込まない

**これは妥協ではなく設計判断。**

日本語 Web フォントは軽量なものでも数百 KB〜数 MB あり、LCP が壊滅する。
クラウドファンディングは SNS からの流入が主で、モバイル回線での初回表示速度が
そのまま支援率に効く。**フォントの美しさより表示速度を取る。**

```css
--font-sans:
  "Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP",
  "Yu Gothic Medium", "Meiryo", system-ui, -apple-system, sans-serif;

/* トークン名・ID・仕様値・コード。UI 上の「機械が読む値」に使う */
--font-mono:
  ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
  "Liberation Mono", monospace;
```

数字を Latin フォントで揃えたい場合でも、**可変フォントのサブセット（数字のみ）に限る**。
本文フォントの差し替えはしない。

### 2.2 タイプスケール

| ロール | サイズ (mobile / desktop) | 行間 | 太さ | トラッキング |
|---|---|---|---|---|
| `display-lg` | 32 / 48px | 1.15 | 700 | −0.02em |
| `display-sm` | 28 / 36px | 1.20 | 700 | −0.02em |
| `heading-lg` | 24 / 30px | 1.30 | 700 | −0.015em |
| `heading-md` | 20 / 24px | 1.35 | 700 | −0.01em |
| `heading-sm` | 18 / 20px | 1.40 | 700 | 0 |
| `title` | 16 / 18px | 1.50 | 600 | 0 |
| `body-lg` | 17 / 18px | **1.80** | 400 | 0 |
| `body` | 16 / 16px | **1.80** | 400 | 0 |
| `body-sm` | 14 / 14px | 1.70 | 400 | 0 |
| `caption` | 13 / 13px | 1.60 | 400 | 0 |
| `label` | 12 / 12px | 1.40 | 600 | +0.04em |
| `numeric-xl` | 28 / 36px | 1.10 | 700 | −0.01em |
| `numeric-lg` | 22 / 24px | 1.15 | 700 | 0 |
| `numeric-md` | 17 / 18px | 1.20 | 700 | 0 |

### 2.3 日本語組版のルール

1. **本文の行間は 1.8。** 欧文の 1.5 をそのまま使うと、漢字の密度で真っ黒に見える。
2. **見出しの行間は 1.15〜1.4。** 本文と同じ 1.8 だと間延びする。
3. **`text-transform: uppercase` を日本語に当てない。** 効かないうえ、
   `letter-spacing` だけが効いて不自然に開く。`label` ロールは Latin ラベル専用。
4. **見出しに `text-wrap: balance`。** 「つくりたいものを、みんなの力 / で。」のような
   最終行1文字だけの折り返しを防ぐ。
5. **本文の1行は 30〜40 文字。** 欧文の 65 文字相当。`max-width: 34em` を目安に。
6. **数字には必ず `font-variant-numeric: tabular-nums`。** 金額・達成率・日数すべて。
7. **禁則処理は `line-break: strict; overflow-wrap: anywhere` を基本に。**
   長い URL やハンドル名がカードを突き破るのを防ぐ。

### 2.4 数値の表記統一

| 対象 | 表記 | 例 |
|---|---|---|
| 金額 | `¥` + カンマ区切り、小数なし | `¥1,234,567` |
| 達成率 | 整数、**切り捨て** | `82%`（99.9% を 100% にしない） |
| 支援者数 | `○人` | `123人` |
| 残り期間 | 24h 以上は日、**切り上げ** | `残り12日` / `残り8時間` |
| 日付 | `YYYY年M月D日` | `2026年3月31日` |
| お届け予定 | 年月まで | `2026年3月` |

**達成率は切り捨て、残り日数は切り上げ。** どちらも「支援者に有利でない側に丸めない」ため。
99.9% を 100% と表示すると誤認になり、47時間を「残り1日」と表示すると不当に急かすことになる。

## 3. スペーシング・レイアウト

### 3.1 スペーススケール（4px 基準）

```
2  4  6  8  12  16  20  24  32  40  48  64  80  96
```

| 用途 | 値 |
|---|---|
| アイコンと文字の間 | 6 / 8 |
| フォームの項目内（ラベル↔入力） | 8 |
| カード内のパディング | 16（モバイル） / 20（デスクトップ） |
| カード間のギャップ | 16 / 20 |
| セクション内の見出し↔内容 | 24 |
| セクション間 | 48（モバイル） / 64〜80（デスクトップ） |

**「なんとなく 15px」を作らない。** スケールにない値を使いたくなったら、
たいていはレイアウトの組み方が間違っている。

### 3.2 グリッドとブレークポイント

| 名前 | 幅 | カード列数 | プロジェクト詳細 |
|---|---|---|---|
| `xs` | < 480px | 1 | 1カラム＋下部固定 CTA |
| `sm` | 480–767 | 1 | 同上 |
| `md` | 768–1023 | 2 | 1カラム＋下部固定 CTA |
| `lg` | 1024–1279 | 3 | 2カラム（8 : 4）・サイドバー sticky |
| `xl` | ≥ 1280 | 3 | 同上・コンテナ最大 1200px |

- コンテナ最大幅 **1200px**、左右パディング **16px**（モバイル）/ **24px**（デスクトップ）
- 12カラムグリッド、ガター **24px**

### 3.3 角丸

用途ごとに変える。**全部同じ角丸にしない**（のっぺりする）。

| トークン | 値 | 用途 |
|---|---|---|
| `radius-xs` | 4px | タグ・小さなチップ |
| `radius-sm` | 8px | ボタン・入力欄 |
| `radius-md` | 12px | カード・リターン |
| `radius-lg` | 16px | モーダル・ボトムシート |
| `radius-full` | 9999px | ピル型バッジ・アバター・進捗バー |

### 3.4 影（エレベーション）

影だけに頼らず、**必ず 1px の枠線と併用**する。白背景に淡い影だけだと、
低品質なディスプレイでカードの輪郭が消える。

| レベル | 値 | 用途 |
|---|---|---|
| `0` | なし（枠線のみ） | 沈んだ面の上のカード |
| `1` | `0 1px 2px rgb(16 19 26 / .06)` | カード（既定） |
| `2` | `0 4px 12px rgb(16 19 26 / .08)` | カードのホバー |
| `3` | `0 8px 24px rgb(16 19 26 / .12)` | ドロップダウン・ポップオーバー |
| `4` | `0 24px 48px rgb(16 19 26 / .18)` | モーダル・ボトムシート |

## 4. コンポーネント仕様

### 4.1 ボタン

#### バリアント

| バリアント | 地 | 文字 | 枠 | 用途 |
|---|---|---|---|---|
| `primary` | `--accent-solid` | 白 | なし | **支援する。1画面に1つ** |
| `secondary` | 白 | `--text-primary` | `--border-default` | 副次操作 |
| `ghost` | 透明 | `--text-secondary` | なし | 補助操作・ツールバー |
| `danger` | `--danger-solid` | 白 | なし | 削除・返金 |
| `link` | 透明 | `--accent-text` | なし | インライン |

#### サイズ

| サイズ | 高さ | 左右padding | 文字 | 用途 |
|---|---|---|---|---|
| `sm` | 32px | 12px | 13 / 600 | テーブル内・補助 |
| `md` | 40px | 16px | 14 / 600 | 既定 |
| `lg` | 48px | 24px | 16 / 700 | 支援 CTA |

**モバイルでは主要 CTA を `lg` かつ幅100%。** タップターゲット最小 44×44px を必ず満たす。

#### 状態（全バリアント必須）

| 状態 | 表現 |
|---|---|
| `default` | 上記のとおり |
| `hover` | 地を1段暗く（`accent/700`）、`shadow-2` |
| `active` | 地をさらに1段暗く（`accent/800`）、`translateY(1px)` |
| `focus-visible` | `outline: 2px solid var(--focus-ring); outline-offset: 2px` |
| `disabled` | 地 `--surface-inset` / 文字 `--text-disabled` / `cursor: not-allowed` |
| `loading` | スピナー＋文言を「処理中…」に。**`disabled` も同時に付ける** |

> **`loading` を必ず実装する。** 支援ボタンの二重送信は実際に起きる。
> UI での防止とサーバー側の冪等性は**両方**必要（[11-payment-hardening.md](11-payment-hardening.md) §5）。

### 4.2 進捗バー

クラファン UI の心臓。

```
仕様
  高さ    : 6px（カード内）/ 8px（詳細ページ）
  角丸    : radius-full
  溝      : --surface-inset
  塗り    : --accent-solid（< 100%）→ --success-solid（≥ 100%）
  アニメ  : width 500ms cubic-bezier(.2,0,0,1)
  上限    : width は 100% で頭打ち。数値表示は 100% を超えて出す
```

- **100% 到達で色を変える。** 達成が一目で分かる瞬間がこのプロダクトの気持ちよさ。
- `role="progressbar"` と `aria-valuenow` / `aria-valuemin` / `aria-valuemax` を必ず付ける
- `aria-valuenow` は 100 で頭打ちにする（254% を渡すと支援技術が壊れる）

### 4.3 プロジェクトカード

一覧の主役。**要素の順番を変えない。** どの一覧でも同じ順で読めることが速さになる。

```
┌────────────────────────┐
│ [カバー 16:9]           │  object-fit: cover / 遅延読込
│  └ カテゴリバッジ(左上)  │  地は白90%＋backdrop-blur
├────────────────────────┤
│ 出品者名                 │  caption / --text-tertiary / 1行省略
│ プロジェクトタイトル      │  title / 600 / 2行でクランプ
│                        │
│ ████████░░░░           │  進捗バー 6px
│ ¥1,234,567    82%      │  numeric-md 700 ＋ 達成率
│ 支援者123人 · 残り12日   │  caption / --text-tertiary
└────────────────────────┘
```

| 項目 | 仕様 |
|---|---|
| 角丸 | `radius-md` (12px) |
| 枠線 | `--border-subtle` 1px |
| 影 | `shadow-1` → hover `shadow-2` |
| ホバー | 画像 `scale(1.03)` 200ms、影を上げる |
| クリック領域 | **カード全体**。タイトルだけリンクにしない |
| 画像なし | カテゴリ絵文字＋`--surface-inset` のプレースホルダ |
| タイトル | 2行クランプ。3行にしない（カードの高さが揃わなくなる） |

### 4.4 リターンカード

```
┌────────────────────────┐
│ ¥10,000                │  numeric-lg
│ CD＋ライブご招待         │  title
│ （説明文 3行クランプ）    │  body-sm / --text-secondary
│ ─────────────────      │
│ 🎁 2026年3月お届け      │  caption
│ 📦 配送あり             │  caption
│ ⚠ 残り5個              │  warning バッジ
│ [ このリターンを選ぶ ]    │  secondary / md / 幅100%
└────────────────────────┘
```

| 状態 | 表現 |
|---|---|
| `default` | 枠線 `--border-subtle` |
| `hover` | 枠線 `--border-strong` |
| `selected` | 枠線 `--accent-solid` 2px＋地 `--accent-bg-subtle` |
| `soldout` | 全体を `opacity: .55`、ボタンを `disabled`、「売り切れました」 |

### 4.5 バッジ

| 種類 | 地 | 文字 | 例 |
|---|---|---|---|
| `neutral` | `--surface-sunken` | `--text-secondary` | 音楽 |
| `warning` | `--warning-bg` | `--warning-fg` | 残り3個 |
| `danger` | `--danger-bg` | `--danger-fg` | 残り2日 |
| `success` | `--success-bg` | `--success-fg` | 目標達成 |
| `info` | `--info-bg` | `--info-fg` | 目標達成でプロジェクト成立 |

仕様: 高さ 22px / 左右 8px / `radius-full` / 12px 600

### 4.6 フォーム

| 要素 | 仕様 |
|---|---|
| 高さ | 40px（`md`）/ 48px（`lg`・モバイル） |
| 枠線 | `--border-default` → focus で `--accent-solid` 1px ＋ focus ring |
| 角丸 | `radius-sm` (8px) |
| 文字 | 16px（**iOS の自動ズームを防ぐため 16px 未満にしない**） |
| ラベル | `<label for>` 必須。プレースホルダで代用しない |
| 必須 | ラベル横に `必須` バッジ。`*` だけにしない |
| エラー | 枠線 `--danger-solid`、下に `--danger-fg` の文言、`aria-describedby` で紐づけ |
| ヘルプ | `caption` / `--text-tertiary` |

**エラー文言は「何が起きたか＋どう直すか」。** 「入力エラー」ではなく
「郵便番号はハイフンなしの7桁で入力してください」。

### 4.7 空状態

0件で白紙を見せない。**必ず次の行動を置く。**

```
        （アイコン）
  検索条件に合うプロジェクトが見つかりませんでした
   条件を変えるか、すべてのプロジェクトから探してみてください。
      [すべてのプロジェクトを見る]  [条件をリセット]
```

### 4.8 スケルトン

スピナーを使わない。**カードの形のまま灰色で出す**。
`--surface-inset` に 1.5s のシマー。`prefers-reduced-motion` で静止。

### 5.2 支援フロー

**1画面1目的。** 選択と入力を同じ画面に詰め込まない。

```
① リターンを選ぶ    → 選択のみ。金額は表示だけ
② 支援内容を確認     → 数量 / 上乗せ / 配送先 / メッセージ
③ 金額の確認        → 内訳を明示。合計を最も大きく
④ 規約に同意        → チェックは既定でオフ
⑤ お支払いへ進む     → Stripe Checkout へ
```

ステップインジケータを上部に固定表示。**目標達成型の場合は③に必ず明記する:**

> このプロジェクトは目標達成時のみ決済されます。
> いまはカード情報の登録のみで、請求は行われません。
> 2026年3月31日の募集終了時点で目標を達成した場合に ¥12,000 が請求されます。

これを書かないと「勝手に引き落とされた」というクレームになる。

## 6. モーション

| トークン | 時間 | 用途 |
|---|---|---|
| `instant` | 100ms | 色の変化・ホバー |
| `fast` | 150ms | ボタンの押下 |
| `base` | 200ms | 影・変形・展開 |
| `slow` | 300ms | モーダル・シート |
| `deliberate` | 500ms | **進捗バーの伸長** |

```css
--ease-standard: cubic-bezier(.2, 0, 0, 1);
--ease-enter:    cubic-bezier(0, 0, 0, 1);
--ease-exit:     cubic-bezier(.3, 0, 1, 1);
```

**動かすもの:** ホバーの影、進捗バー、モーダル、トースト、スケルトン、達成の瞬間。
**動かさないもの:** それ以外。特に**スクロール連動アニメーションは入れない**。
支援を邪魔するうえ、モバイルで重い。

`prefers-reduced-motion: reduce` で全アニメーションを 0.01ms に落とす。

## 7. 画像

| 用途 | サイズ | 比率 | 備考 |
|---|---|---|---|
| カバー | 1200×675 | 16:9 | 必須。OGP にも使う |
| 本文中 | 幅1200 以下 | 自由 | 最大30枚 |
| リターン | 800×800 | 1:1 | 任意 |

- `next/image` の `sizes` を正しく指定する（指定漏れは LCP に直結）

## 9. ライティング

### 9.1 トーン

**「購入」ではなく「支援」。** 購入型クラファンだが、体験としては応援である。

| 場面 | ✕ | ○ |
|---|---|---|
| CTA | 決済する / 購入する | このプロジェクトを支援する |
| 出品導線 | 出品登録 | プロジェクトを始める |
| 不成立 | 失敗しました | 目標に届きませんでした。ご支援は請求されません |
| エラー | エラーが発生しました | 決済に失敗しました。カード情報をご確認ください |
| 手数料 | 手数料 13.6% | 手数料 13.6%（サービス利用料10% + 決済手数料3.6%） |
| 空状態 | データがありません | まだプロジェクトがありません。最初の1つを作りませんか |

### 9.2 ボタンの文言は「何が起きるか」

`OK` / `送信` を使わない。`公開する` / `支援を確定する` / `差し戻す`。
押した後のトーストは過去形で対応させる（`公開する` → `公開しました`）。

### 9.3 手数料と決済タイミングは必ず明示

隠さない。**先に言うほど信用される。**

## 10. 実装への引き渡し

### 10.1 CSS 変数と Tailwind の対応

Tailwind v4 の `@theme` でトークンをユーティリティに落とす。

```css
@theme inline {
  --color-surface-page:   var(--surface-page);
  --color-accent-solid:   var(--accent-solid);
  --color-text-primary:   var(--text-primary);
  /* … §1.2 のトークンをすべて写像 */
  --radius-xs: 4px;  --radius-sm: 8px;
  --radius-md: 12px; --radius-lg: 16px;
}
```

### 10.2 守るべき実装ルール

1. **コンポーネントの CSS に生の hex を書かない。** 必ずトークン経由。
   これを破った時点でダークモードの追加が不可能になる
2. **スペーススケールにない値を使わない**
3. **金額表示は必ず共通コンポーネント経由**（`formatJpy`）。
   直接 `toLocaleString` を呼ばない
4. **アクセントを CTA と進捗バー以外に使わない**
5. 新しいコンポーネントを作る前に、既存の組み合わせで済まないか確認する

### 10.3 チェック手順

```
1. design/styleguide.html をブラウザで開く（ビルド不要）
2. 実装したコンポーネントと見比べる
3. ズレていたら、styleguide 側ではなく実装側を直す
4. 仕様を変えるときは、この文書 → styleguide → 実装 の順で更新する
```
