# 07. デザインシステム

方向性: **CAMPFIRE 風・明るく万人向け**。白基調、カードが並ぶ、誰が見ても「安心して支援できる」トーン。
音楽発のサービスだが、出品者は音楽以外にも広げるので**尖らせすぎない**。差別化は色ではなく「音楽カテゴリの充実」でやる。

---

## 1. 原則

1. **白基調・カード主役。** 背景は白〜極薄グレー。情報はすべてカードに載る。
2. **アクセントカラーは1色だけ。** 支援ボタンと進捗バーにのみ使う。他の場所で使うとCTAが埋もれる。
3. **金額と達成率が主役。** ページ内で一番大きく・濃い文字は必ず金額。
4. **余白を詰めない。** 情報量が多いサービスなので、詰めると一気に安っぽくなる。
5. **写真がすべて。** カバー画像の品質でプロジェクトの印象が決まる。アップロード時に推奨サイズ（1200×675 / 16:9）を明示し、プレビューを見せる。

---

## 2. カラートークン

CSS 変数として `globals.css` に定義し、Tailwind から参照する。

```css
:root {
  /* ベース */
  --bg:            #ffffff;
  --bg-subtle:     #f7f8fa;   /* セクション背景・カード外の地 */
  --bg-muted:      #eef0f4;   /* 進捗バーの溝・スケルトン */
  --border:        #e3e6ec;
  --border-strong: #c9cdd6;

  /* テキスト */
  --fg:            #14161a;   /* 見出し・金額 */
  --fg-secondary:  #4c525e;   /* 本文 */
  --fg-muted:      #6b7280;   /* 補助・キャプション（AA 4.5:1 を満たす濃さ） */

  /* アクセント（CTA・進捗バー） */
  --accent:        #ff5a4d;   /* コーラルレッド */
  --accent-hover:  #ec4436;
  --accent-active:  #d3392c;
  --accent-subtle: #fff1ef;   /* バッジ背景 */
  --accent-fg:     #ffffff;   /* アクセント上の文字 */

  /* サブ（出品者・リンク） */
  --brand-deep:    #1c2a44;   /* 濃紺。ヘッダー文字・フッター */

  /* 状態 */
  --success:       #12855a;   /* 達成・成立 */
  --success-subtle:#e8f6ef;
  --warning:       #b26a00;   /* 残りわずか・締切間近 */
  --warning-subtle:#fff5e5;
  --danger:        #c62828;   /* エラー・不成立 */
  --danger-subtle: #fdecec;
  --info:          #1666c4;
  --info-subtle:   #eaf2fd;

  /* 影 */
  --shadow-sm: 0 1px 2px rgba(20,22,26,.06);
  --shadow-md: 0 4px 12px rgba(20,22,26,.08);
  --shadow-lg: 0 12px 32px rgba(20,22,26,.12);
}
```

### コントラスト確認（WCAG AA）

| 組み合わせ | 比 | 判定 |
|---|---|---|
| `--fg` on `--bg` | 15.8:1 | ◎ |
| `--fg-secondary` on `--bg` | 8.4:1 | ◎ |
| `--fg-muted` on `--bg` | 4.9:1 | ○ |
| 白 on `--accent` | 3.1:1 | △ **ボタンは 16px / 太字（=大きい文字）で使う。** 大きい文字は 3:1 で AA |
| `--accent` on `--bg` | 3.1:1 | △ **リンクや小さい文字の色には使わない。** 塗りボタンとバーの塗りにのみ使用 |

数値は実装時に必ず再計測すること。色を1つでも変えたら全部ずれる。

**`--accent` を細い文字色として使わないこと。** コーラル系は白背景で読みづらい。テキストリンクは `--info` を使う。

### ダークモード

初期は**やらない**。工数に対して効果が薄い。
将来やるときのために色は CSS 変数で定義してあるので、`@media (prefers-color-scheme: dark)` で上書きすれば済む構造にしておく。

## 3. タイポグラフィ

```css
--font-sans: "Hiragino Sans", "Noto Sans JP", "Yu Gothic Medium",
             system-ui, -apple-system, sans-serif;
--font-num:  "Inter", system-ui, sans-serif;   /* 金額・数字用 */
```

**Web フォントを読み込まない。** 日本語 Web フォントは数MBあり、LCP が壊滅する。OS フォントで十分きれいに見える。
数字だけ `Inter` を可変フォントで読み込むのは可（サブセット化必須）。

| 用途 | サイズ | 太さ | 行間 |
|---|---|---|---|
| ページ見出し (h1) | 28 / 36px (sm/lg) | 700 | 1.35 |
| セクション見出し (h2) | 20 / 24px | 700 | 1.4 |
| カードタイトル | 16px | 600 | 1.5（2行でクランプ） |
| 本文 | 16px | 400 | **1.8**（日本語は広めに） |
| 金額（大） | 28 / 32px | 700 | 1.2 / tabular-nums |
| 金額（カード内） | 18px | 700 | 1.2 / tabular-nums |
| 補助テキスト | 13px | 400 | 1.6 |

**金額には必ず `font-variant-numeric: tabular-nums` を当てる。** 桁が揃わないと一覧が汚く見える。

## 4. スペーシング・角丸

```
spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px（Tailwind の 1,2,3,4,6,8,12,16）
radius:  sm 6px / md 10px / lg 14px / full 9999px
```

- カードの角丸は `lg (14px)`。丸すぎるとカジュアルになりすぎ、角ばると硬い。
- ボタンは `md (10px)`。
- コンテナ最大幅 `1200px`、左右パディング `16px`（モバイル）/ `24px`（デスクトップ）。

## 5. 主要コンポーネント仕様

### ProjectCard

```
┌──────────────────────────┐
│ [16:9 カバー画像]         │  ← object-cover, next/image, 遅延読込
│                          │     カテゴリバッジを左上にオーバーレイ
├──────────────────────────┤
│ [🎵] 出品者名             │  20px アバター + 13px muted
│ プロジェクトタイトル       │  16px/600, 2行クランプ
│                          │
│ ████████░░░░  82%        │  進捗バー 6px, accent
│ ¥1,234,567               │  18px/700 tabular-nums
│ 支援者123人 · 残り12日     │  13px muted
└──────────────────────────┘
```

- ホバー: `shadow-md` へ、画像を `scale(1.03)` （200ms）
- 全体がリンク。クリック領域を広く取る
- 画像がないプロジェクトはプレースホルダ（カテゴリ絵文字＋淡色背景）

### ProgressBar

```tsx
<div className="h-1.5 rounded-full bg-[--bg-muted] overflow-hidden"
     role="progressbar" aria-valuenow={pct} aria-valuemin={0} aria-valuemax={100}>
  <div className="h-full rounded-full transition-[width] duration-500"
       style={{ width: `${Math.min(pct, 100)}%`,
                background: pct >= 100 ? 'var(--success)' : 'var(--accent)' }} />
</div>
```

**100% 到達で色を `--success` に変える。** 達成が一目で分かるのが気持ちいい。

### 支援ボタン（プライマリ CTA）

```
背景 --accent / 文字 白 / 16px 700 / padding 14px 24px / radius 10px
hover: --accent-hover, 影 md
active: --accent-active, translateY(1px)
disabled: --bg-muted 背景 + --fg-muted 文字
モバイル: 画面下固定バー内で幅100%（safe-area-inset-bottom を考慮）
```

**モバイルの固定 CTA バーには金額サマリーも入れる:**
```
┌────────────────────────────────┐
│ ¥1,234,567 · 82%  [支援する]   │
└────────────────────────────────┘
```

### バッジ

| 種類 | 色 | 例 |
|---|---|---|
| カテゴリ | `--bg-subtle` / `--fg-secondary` | 音楽 |
| 残りわずか | `--warning-subtle` / `--warning` | 残り3個 |
| 締切間近 | `--danger-subtle` / `--danger` | 残り2日 |
| 達成 | `--success-subtle` / `--success` | 目標達成 |
| All-or-Nothing | `--info-subtle` / `--info` | 目標達成でプロジェクト成立 |

### EmptyState

0件のときに白紙を見せない。必ず**次の行動**を置く。

```
    🔍
検索条件に合うプロジェクトが見つかりませんでした
      [条件をリセット]  [すべてのプロジェクトを見る]
```

## 6. アクセシビリティ

- [ ] すべてのインタラクティブ要素にフォーカスリング（`--accent` の 2px outline + 2px offset）
- [ ] 進捗バーに `role="progressbar"` と aria 属性
- [ ] 画像に `alt`。装飾画像は `alt=""`
- [ ] 色だけで情報を伝えない（「残りわずか」は色＋文言の両方）
- [ ] フォームのラベルは `<label for>` で明示。プレースホルダをラベル代わりにしない
- [ ] エラーは `aria-describedby` で入力欄に紐づける
- [ ] タップターゲット最小 44×44px
- [ ] `prefers-reduced-motion` でアニメーションを無効化

---

## 7. ローディング・スケルトン

一覧・詳細ともスピナーではなく**スケルトン**を使う。カードの形をそのまま灰色で出す。
Next.js の `loading.tsx` に置けば App Router が自動で出してくれる。

支援ボタンは押した瞬間に `disabled` + 「処理中…」に変える。**二重送信を UI でも防ぐ**（サーバー側の冪等性と両方やる）。

---

## 8. コピーライティングのトーン

| 場面 | ✕ | ○ |
|---|---|---|
| CTA | 決済する | このプロジェクトを支援する |
| 出品導線 | 出品登録 | プロジェクトを始める |
| 不成立通知 | 失敗しました | 目標に届きませんでした。ご支援は請求されません |
| エラー | Error: payment failed | 決済に失敗しました。カード情報をご確認ください |
| 手数料説明 | 手数料 13.6% | 手数料 13.6%（サービス利用料10% + 決済手数料3.6%） |

**「購入」ではなく「支援」。** 購入型クラファンだが、体験としては応援である。言葉づかいがサービスの空気を決める。
