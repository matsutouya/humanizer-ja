### プロジェクト詳細 `/projects/[slug]` ← 最重要画面

デスクトップは 2 カラム、モバイルは 1 カラム + 下部固定 CTA。

```
┌─────────────────────────────────┬─────────────────┐
│ カバー画像 / 動画                │ ■ 支援サマリー   │
│                                  │ ¥1,234,567      │
│ プロジェクトタイトル              │ ████████░░ 82%  │
│ キャッチコピー                    │ 目標 ¥1,500,000 │
│                                  │ 支援者 123人     │
│ [出品者アイコン] 出品者名 >       │ 残り 12日        │
│                                  │                 │
│ ─ タブ ────────────────────      │ [このプロジェクト │
│ ストーリー | 活動報告(3) |        │  を支援する]     │
│ コメント(45) | 支援者              │                 │
│                                  │ ─ リターン ─    │
│ （本文 Markdown）                 │ ┌─────────────┐ │
│                                  │ │ ¥3,000      │ │
│                                  │ │ デジタル音源  │ │
│                                  │ │ 残り 無制限   │ │
│                                  │ │ 2026年3月    │ │
│                                  │ │ [選択する]   │ │
│                                  │ └─────────────┘ │
│                                  │ ┌─────────────┐ │
│                                  │ │ ¥10,000     │ │
│                                  │ │ CD + ライブ  │ │
│                                  │ │ 残り 5個 ⚠  │ │
│                                  │ └─────────────┘ │
└─────────────────────────────────┴─────────────────┘
```

**必ず入れる要素**
- 達成率の進捗バー（100% 超えたら色を変える）
- 残り日数（24時間切ったら「残り○時間」に切り替え）
- 資金調達方式のバッジ（All-in なら「目標未達でも実行」の説明ツールチップ）
- 出品者への信頼要素（過去の実績プロジェクト数）
- SNS シェアボタン（X / LINE / URL コピー）
- 通報リンク（フッター近くに小さく）

**モバイルでは支援ボタンを画面下に固定表示する。** これがないと支援率が落ちる。

### リターン選択・支援確認 `/pledge/[projectSlug]`

```
1. リターンを選ぶ（カード選択 UI）
2. 数量を選ぶ（在庫上限まで）
3. 上乗せ支援額を入力（任意・0円可）
4. 配送先入力（配送要リターンのみ）
5. 応援メッセージ（任意）・匿名にするチェック
6. 金額確認
     リターン ¥10,000 × 1
     上乗せ支援     ¥2,000
     ───────────────────
     合計          ¥12,000
7. 規約同意チェック
8. [お支払いへ進む] → Stripe Checkout へリダイレクト
```

**All-or-Nothing の場合はここに必ず明記する:**
> このプロジェクトは目標達成時のみ決済されます。
> 現時点ではカード情報の登録のみで、請求は行われません。
> 2026年3月31日の募集終了時点で目標を達成した場合に ¥12,000 が請求されます。

これを書かないと「勝手に引き落とされた」というクレームになる。

### 出品者ダッシュボード `/creator`

```
┌────────────────────────────────────┐
│ ⚠ 入金先の登録が完了していません    │  ← 未完了なら最上部に警告
│   [Stripe で登録を続ける]           │
├────────────────────────────────────┤
│ 進行中のプロジェクト                 │
│ ┌──────────────────────────────┐  │
│ │ [画像] タイトル                │  │
│ │ ████████░░ 82%  ¥1,234,567   │  │
│ │ 支援者 123人 / 残り 12日       │  │
│ │ 受取見込 ¥1,066,265（手数料後）│  │
│ │ [編集] [支援者] [活動報告]     │  │
│ └──────────────────────────────┘  │
├────────────────────────────────────┤

├────────────────────────────────────┤
```

**受取見込額を必ず表示する。** 手数料を後から知って揉めるのが一番多いトラブル。

```
審査待ち: 3件

┌──────────────────────────────────────────┐
│ [画像] タイトル                            │
│ 出品者: 名前（過去実績 0件）  申請 2時間前  │

```

差戻し時は理由の入力を必須にする。

## レスポンシブ・ブレークポイント

Tailwind デフォルトに合わせる。

| 幅 | 対応 |
|---|---|
| < 640px (sm 未満) | 1 カラム。プロジェクト詳細は下部固定 CTA。カードは 1 列 |
| 640–1024px | カード 2 列。詳細は 1 カラムのまま |
| ≥ 1024px (lg) | カード 3 列。詳細は 2 カラム（サイドバー sticky） |
| ≥ 1280px | 最大幅 1200px で中央寄せ |

## 共通コンポーネント

| コンポーネント | 用途 |
|---|---|
| `<ProjectCard>` | 一覧のカード。画像・タイトル・出品者・進捗バー・達成率・残り日数 |
| `<ProgressBar>` | 進捗バー。100% 超で色変化。`aria-valuenow` を付ける |
| `<RewardCard>` | リターン1件。在庫切れは選択不可＋グレーアウト |
| `<AmountDisplay>` | 金額表示。`¥1,234,567` 形式で統一（`toLocaleString('ja-JP')`） |
| `<DaysLeft>` | 残り日数。24時間未満は時間表示 |
| `<FundingTypeBadge>` | All-in / All-or-Nothing のバッジ＋説明 |
| `<CreatorAvatar>` | 出品者アイコン＋名前 |
| `<EmptyState>` | 0件時の表示。必ず次のアクションを示す |
| `<ShareButtons>` | X / LINE / URL コピー |

## OGP（SNS シェア時の画像）

プロジェクト詳細に `opengraph-image.tsx` を置いて動的生成する。

```
┌────────────────────────────────┐
│  [カバー画像を背景にぼかし]      │
│                                │
│  プロジェクトタイトル            │
│  ████████░░ 82% 達成            │
│  ¥1,234,567 / 支援者 123人      │
│                                │
│  FUNDBEAT                      │
└────────────────────────────────┘
```

**達成率を画像に焼き込むのが効く。** シェアされたときに「もう少しで達成」が見えると支援が伸びる。
