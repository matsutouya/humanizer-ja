## 2. 支援（購入）に関する表記

> ▶ 起草メモ（公開時に削除）
> ここは「支援者から見た取引条件」の共通部分。個別のリターン内容は各プロジェクトページに表示する。

### 支援金額

各プロジェクトページに表示するリターンごとの金額によります。表示金額はすべて**消費税込みの総額**です。

### 支援金額以外に必要な費用

- 送料の要否および金額は、各リターンの説明に記載します。
- 上乗せ支援を選択した場合、その金額が加算されます。

### 支払方法

クレジットカード（Apple Pay、Google Pay を含みます）

### 支払時期

| 資金調達方式 | 支払時期 |
|---|---|
| 実行確定型（All-in） | 支援の申込み時に決済されます |
| 目標達成型（All-or-Nothing） | **申込み時は決済されません。**募集期間の終了時に目標金額を達成した場合に、登録されたクレジットカードに請求されます |

### リターンの提供時期

各リターンに表示するお届け予定時期によります。**お届け予定時期は目安であり、遅延が生じる場合があります。**遅延が見込まれる場合、出品者から活動報告等により通知されます。

### キャンセル・返品について

- **実行確定型における支援は、決済完了後にキャンセルすることはできません。**
- **目標達成型における支援は、募集期間中に限りキャンセルできます。**募集期間の終了後はキャンセルできません。
- **リターンの性質上、支援者の都合による返品・交換はお受けできません。**
- 次の場合には、返金の手続きを行います。
  - プロジェクトが中止された場合
  - 当社がプロジェクトを非公開とした場合
  - 決済の重複その他の誤りがあった場合
- リターンに不良、破損または内容の相違がある場合は、**出品者にお問い合わせください。**

> ▶ 起草メモ（公開時に削除）
> **通信販売にクーリングオフの適用はないが、「返品特約」の表示がないと
> 8日間の返品が可能になってしまう。** 上記の返品不可の記載は必ず入れ、
> かつ **支援申込画面にも同じ内容を再掲する**こと（表示していないと有効性が争われる）。
> ⚖️ 弁護士確認。

### 動作環境

本サービスは、最新版の主要なウェブブラウザでの利用を推奨します。

## 3. 出品者の表記について

**本サービスに掲載される各プロジェクトについて、支援者と直接取引を行うのは出品者です。**

各プロジェクトの詳細ページに、当該プロジェクトの出品者に関する下記の情報を表示しています。ご支援の前に必ずご確認ください。

- 出品者の氏名または名称
- 所在地
- 連絡先
- リターンの内容、金額、お届け予定時期、送料
- リターンに関する問い合わせ先

> ▶ 起草メモ（公開時に削除）
> **これは実装が必要な項目。** [03-db-schema.md](../docs/03-db-schema.md) の
> `CreatorProfile` に `legalName` は持たせているが、**住所・電話番号のフィールドがまだない。**
> スキーマに追加すること：
>
> ```prisma
> model CreatorProfile {
>   // ... 既存
>   legalName    String?
>   postalCode   String?
>   address      String?
>   phoneNumber  String?
>   /// 住所・電話番号を常時公開するか、請求時に開示するか
>   disclosureMode CreatorDisclosureMode @default(ON_REQUEST)
> }
>
> enum CreatorDisclosureMode {
>   PUBLIC      // 常時公開
>   ON_REQUEST  // 請求があれば遅滞なく開示
> }
> ```
>
> ⚖️ 弁護士確認 G-5：個人出品者の住所公開は現実的にハードルが高い。
> 「請求があれば遅滞なく開示する」方式が認められるかを確認し、
> 認められる場合は下記の表記を使う。認められない場合は常時公開が必要になり、
> **出品者の獲得に直結する重大な仕様**になる。

### 出品者の所在地・電話番号の開示について
