## はじめに

【要記入：A-1】（以下「本サービス」）は、つくりたいものを持つ人と、それを応援したい人をつなぐ場です。

安心して支援していただくために、掲載できるプロジェクトには基準を設けています。
**すべてのプロジェクトは、公開前に運営が審査します。**

本ガイドラインは[利用規約](terms.md)の一部を構成します。

## 1. 掲載できるプロジェクトの基本条件

すべて満たす必要があります。

- [ ] 出品者本人が主体となって実行する企画であること
- [ ] リターンの内容、金額、お届け予定時期が具体的に記載されていること
- [ ] リターンの提供に必要な**許認可、届出、権利者の許諾を取得済み**であること
- [ ] 資金の使い道が説明されていること
- [ ] 出品者の連絡先が確認できること
- [ ] 目標金額が、企画の内容に照らして合理的であること

## 2. 掲載できないプロジェクト

### 2.1 金銭的リターンを伴うもち（最重要）

**本サービスは購入型クラウドファンディングです。**次のものは掲載できません。

- 投資、出資、株式、社債、ファンドの持分
- 融資、貸付、利息の支払を伴うもの
- 配当、分配金、売上の分配を約するもの
- 元本の返還を約するもの
- 暗号資産、NFT等のうち、投資性・換金性を有するもの
- 金券、商品券、ギフトカード、ポイント等の換金性の高いもの

> ▶ 起草メモ（公開時に削除）
> **審査で最も注意する項目。** 該当すると金融商品取引法・貸金業法の登録が必要になり、
> Stripe のアカウント停止にも直結する。
> 「支援してくれた方に売上の○%を還元します」という記載は**即座に差戻し**。

### 2.2 法令上の許認可を要するもの（当面すべて不可）

運営体制が整うまで、次のジャンルは取り扱いません。

| ジャンル | 関係法令 |
|---|---|
| 酒類の販売 | 酒税法（通信販売酒類小売業免許） |
| 食品の製造・販売 | 食品衛生法（営業許可、アレルギー表示） |
| 医薬品、医薬部外品、医療機器 | 医薬品医療機器等法（薬機法） |
| 化粧品 | 薬機法 |
| 健康食品のうち効能を標榜するもの | 薬機法 |
| 中古品の売買 | 古物営業法（古物商許可） |
| 有価証券、金融商品 | 金融商品取引法 |
| 保険 | 保険業法 |
| 旅行商品の企画・手配 | 旅行業法 |
| 不動産の取引 | 宅地建物取引業法 |

> ▶ 起草メモ（公開時に削除）
> 将来これらを解禁する場合、**許認可の証憑を提出させる審査フロー**が必要になる。
> 初期は全面的に不可とするのが安全。CD・グッズ・ライブ・デジタル音源は
> このリストに該当しないので、音楽プロジェクトは問題なく掲載できる。

### 2.3 権利を侵害するもの

- 第三者の著作権、商標権、意匠権、特許権を侵害するもの
- 第三者の肖像権、パブリシティ権を侵害するもの
- 権利者の許諾を得ていない**カバー楽曲、サンプリング、リミックス**
- 無断で他人の写真、イラスト、映像を使用したもの
- 他のクラウドファンディングサイトに掲載中の同一プロジェクト

> ▶ 起草メモ（公開時に削除）
> **音楽サービスとして最も重要な項目。**
> リターンに音源を含む場合、**著作権（作詞・作曲）と原盤権（レコーディング）の両方**が必要。
> カバー曲を配布する場合は JASRAC / NexTone への手続きが必要になる。
> 審査時に「オリジナル曲か / カバーか」「権利処理の状況」を確認する項目を設ける。

### 2.4 公序良俗に反するもの

- 犯罪、違法行為を助長するもの
- アダルト、性的な表現を主目的とするもの
- 暴力的、残虐な表現を主目的とするもの
- 特定の個人、団体、属性に対する誹謗中傷、差別、ヘイトスピーチ
- 自傷行為、自殺を助長するもの
- 反社会的勢力が関与するもの
- 政治団体、宗教団体の活動を目的とするもの

### 2.5 その他

- 実体のない企画、資金使途が不明なもの
- 現金、金券のみをリターンとするもの
- 出品者以外の第三者が主体となる企画（代理での掲載）
- 同一の企画を複数のアカウントから重複して掲載するもの
- 生体、動植物の販売
- 武器、爆発物、その他危険物
- 個人情報の取得を主目的とするもの
- **効果・効能について合理的な根拠のない表示**（景品表示法）

## 3. 表現に関するルール

### 3.1 使ってはいけない表現

| ✕ | 理由 |
|---|---|
| 「必ず」「絶対に」「100%」 | プロジェクトの実現は保証できない |
| 「業界No.1」「日本初」（根拠なし） | 景品表示法の優良誤認表示 |
| 「治る」「効く」「痩せる」 | 薬機法 |
| 「元が取れる」「儲かる」 | 投資性の誤認 |
| 通常価格を実際より高く見せる二重価格表示 | 景品表示法の有利誤認表示 |

### 3.2 必ず記載すること

- リターンの内容（数量、サイズ、色、仕様）
- お届け予定時期（**余裕を持った時期を設定してください**）
- 送料の有無と金額
- 配送の対象地域
- 遅延が生じる可能性があること

## 4. 審査について

### 4.1 審査の流れ

```
下書き作成 → 審査申請 → 運営が審査 → 承認 / 差戻し / 却下
                              ↓ 承認
                         指定した開始日に公開
```

- 審査には**【要記入：例 3営業日】程度**いただきます。
- 差戻しの場合、理由をお伝えします。修正のうえ再申請してください。
- **審査は、プロジェクトの実現やリターンの提供を運営が保証するものではありません。**

### 4.2 審査で確認する項目

> ▶ 起草メモ（公開時に削除）
> ここから下は**運営の審査チェックリスト**。管理画面に同じ項目を実装する。

- [ ] 第2章の禁止事項に該当しないか
- [ ] リターンの内容・金額・お届け時期が具体的か
- [ ] 目標金額とリターンの原価・数量に整合性があるか（**明らかに赤字になる設計になっていないか**）
- [ ] お届け予定時期が現実的か（短すぎないか）
- [ ] 画像・楽曲・映像の権利が出品者にあるか
- [ ] 資金使途の説明があるか
- [ ] 出品者の本人確認・入金先登録が完了しているか
- [ ] 禁止表現が含まれていないか
- [ ] 送料の記載があるか（配送を伴う場合）
- [ ] 連絡先が有効か

### 4.3 公開後の対応

当社は、公開後であっても、次の場合にプロジェクトを非公開とすることがあります。

- 本ガイドラインまたは利用規約への違反が判明した場合
- 掲載内容に重大な虚偽があった場合
- 第三者から権利侵害の申立てがあり、正当と認められる場合
- 出品者と連絡が取れなくなった場合

非公開とした場合、支援者に対して返金の手続きを行うことがあります。

## 5. 出品者の義務

### 5.1 リターンの提供

**リターンの提供は、出品者が支援者に対して負う義務です。**運営が代わりに履行することはありません。

- お届け予定時期を過ぎる見込みとなった場合、**速やかに活動報告で通知してください。**
- 支援者からの問い合わせには誠実に対応してください。
- 提供が困難となった場合、直ちに運営にご相談ください。

### 5.2 活動報告

支援者は、資金の使途と進捗を知る権利があります。**募集終了後も、リターンの提供が完了するまで、定期的に活動報告を投稿してください。**

推奨頻度：**月1回以上**

### 5.3 やってはいけないこと

- 自分のプロジェクトを自分で支援すること（第三者を通じた場合を含む）
- 支援者を装って応援コメントを投稿すること
- 集まった資金を、掲載した使途と異なる目的に使用すること
- 支援者の個人情報を、リターンの提供以外の目的に利用すること
- 支援者に対して、本サービス外での取引を持ちかけること

## 6. 支援者の方へ

### 6.1 支援の前に確認してください

- **クラウドファンディングは、商品の購入とは異なります。**プロジェクトが計画どおりに進まない可能性があります。
- お届け予定時期は**目安**です。遅延が生じることがあります。
- **実行確定型（All-in）の支援は、決済後にキャンセルできません。**
- リターンに関する問い合わせは、**出品者に対して**行ってください。

### 6.2 通報

ガイドラインに違反すると思われるプロジェクトを見つけた場合、各プロジェクトページの「通報する」からご連絡ください。
