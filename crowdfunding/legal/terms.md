## 第1章 総則

### 第1条（目的および適用）

1. 本規約は、【要記入：A-4】（以下「当社」といいます）が提供するクラウドファンディングサービス「【要記入：A-1】」（以下「本サービス」といいます）の利用条件を定めるものです。
2. 本サービスを利用するすべての方（以下「利用者」といいます）は、本規約に同意したうえで本サービスを利用するものとします。
3. 当社が本サービス上で掲載する各種ガイドライン、ヘルプ、注意事項等は、本規約の一部を構成します。本規約と個別の定めが異なる場合は、個別の定めが優先します。

### 第2条（定義）

本規約において、次の各号の用語は以下の意味を有します。

| 用語 | 定義 |
|---|---|
| プロジェクト | 出品者が本サービス上に掲載し、支援を募集する企画 |
| 出品者 | 当社の承認を受け、プロジェクトを掲載する会員 |
| 支援者 | プロジェクトに対して支援を行う会員 |
| 支援 | 支援者がリターンを選択し、対価を支払うことを申し込む行為 |
| リターン | 支援に対して出品者が支援者に提供する商品、サービスまたは権利 |
| 支援契約 | 支援者と出品者との間で成立する、リターンの提供を内容とする契約 |
| 実行確定型 | 目標金額の達成有無にかかわらずプロジェクトを実行する方式（All-in） |
| 目標達成型 | 目標金額を達成した場合にのみ支援契約が成立する方式（All-or-Nothing） |
| 募集期間 | プロジェクトの掲載開始日から募集終了日までの期間 |
| 決済事業者 | 当社が本サービスにおいて利用する決済代行事業者 |

### 第3条（本サービスの性質）

1. **本サービスは、購入型クラウドファンディングのプラットフォームです。**支援は、リターンの提供を受けることを目的とする取引であり、**投資、融資、預金、寄付のいずれでもありません。**
2. **支援契約は、支援者と出品者との間で直接成立します。当社は支援契約の当事者ではなく、本サービスの場を提供する者にとどまります。**
3. 当社は、リターンの内容、品質、提供時期その他プロジェクトの実現について、保証するものではありません。
4. 支援は、リターンの提供と引き換えに対価を支払うものであり、**金銭的な利益、配当、元本の返還を約するものではありません。**

### 第4条（本規約の変更）

1. 当社は、次の各号のいずれかに該当する場合、本規約を変更することができます。
   1. 変更が利用者の一般の利益に適合するとき
   2. 変更が契約をした目的に反せず、変更の必要性、変更後の内容の相当性その他の事情に照らして合理的なものであるとき
2. 当社は、前項による変更にあたり、変更後の本規約の内容および効力発生日を、効力発生日の【要記入：例 14】日前までに本サービス上に掲示する方法により周知します。

2. 当社は、次の各号に該当すると判断した場合、登録を承認しないことがあります。
   1. 申請内容に虚偽、誤記または記入漏れがある場合
   2. 過去に本規約または当社の他のサービスの規約に違反したことがある場合
   3. 反社会的勢力に該当し、または関与していると認められる場合
   4. その他当社が不適当と判断した場合
3. 未成年者が本サービスを利用する場合、あらかじめ法定代理人の同意を得るものとします。

### 第6条（アカウントの管理）

1. 利用者は、自己の責任においてアカウント情報を管理するものとします。
2. アカウントの第三者への貸与、譲渡、売買、共用は禁止します。
3. アカウント情報を用いて行われた行為は、当該アカウントの利用者本人による行為とみなします。ただし、当社の故意または重大な過失により第三者に情報が漏えいした場合は、この限りではありません。

### 第7条（退会）

1. 利用者は、当社の定める方法により、いつでも退会することができます。
2. 次の各号に該当する場合、退会することはできません。
   1. 出品者として、募集中または実行中のプロジェクトを有する場合
   2. 支援者として、リターンの提供を受けていない支援がある場合
   3. 当社に対する債務を履行していない場合
3. 退会後も、法令上の保存義務がある取引記録および会計記録は、当社が定める期間保存します。
4. **退会により、保有する応援ポイントは消滅します。**

### 第8条（利用停止および登録抹消）

1. 当社は、利用者が次の各号に該当すると判断した場合、事前の通知なく、本サービスの利用停止、投稿の削除、プロジェクトの非公開化、登録の抹消その他必要な措置を講じることができます。
   1. 本規約またはガイドラインに違反した場合
   2. 登録情報に虚偽があった場合
   3. 支払を怠った場合
   4. 反社会的勢力に該当し、または関与していると認められる場合
   5. 当社の業務を妨害した場合
   6. その他当社が不適切と判断した場合
2. 当社は、前項の措置により利用者に生じた損害について、当社の故意または重大な過失による場合を除き、責任を負いません。
3. 前項の措置がプロジェクトの非公開化を伴う場合、当社は第21条に従い、支援者に対して返金の手続きを行うことがあります。

## 第3章 プロジェクトの掲載（出品者）

### 第9条（出品者の資格）

1. 出品者となるためには、会員登録に加え、当社の定める出品者申請を行い、当社の承認を得る必要があります。
2. 出品者は、日本国内に住所または本店所在地を有する者に限ります。
3. 出品者は、決済事業者が定める手続きに従い、本人確認および入金先口座の登録を完了しなければなりません。**当該手続きが完了するまで、プロジェクトを公開することはできません。**
4. 出品者は、【要記入：E-5】歳以上であることを要します。

### 第10条（掲載の申請および審査）

1. 出品者は、当社の定める方法によりプロジェクトの掲載を申請します。
2. **当社は、申請されたすべてのプロジェクトについて、公開前に審査を行います。**当社は、審査の基準および結果について、その理由の一部または全部を開示しないことがあります。
3. 当社は、審査の結果、掲載を承認しないこと、または修正を求めることができます。
4. **審査は、プロジェクトの実現可能性、リターンの提供、出品者の信用力等を当社が保証するものではありません。**

### 第11条（掲載内容に関する責任）

1. プロジェクトの掲載内容（文章、画像、動画、リターンの条件を含みます）は、**すべて出品者が作成し、その内容についてはすべて出品者が責任を負います。**
2. 出品者は、掲載内容が次の各号に適合することを保証します。
   1. 事実に反する記載、誇大な表現または誤認を生じさせる表現を含まないこと
   2. 第三者の知的財産権、肖像権、プライバシーその他の権利を侵害しないこと
   3. 法令および本サービスのガイドラインに違反しないこと
   4. リターンの内容および提供時期が具体的かつ実現可能であること
3. 出品者は、リターンの提供に許認可、届出または権利者の許諾を要する場合、**あらかじめこれらを取得したうえで**掲載を申請しなければなりません。

## 第4章 支援（支援者）

### 第17条（支援契約の成立）

1. 支援者は、プロジェクトのリターンを選択し、当社の定める方法により支援を申し込みます。
2. 支援契約の成立時期は、資金調達方式に応じて次のとおりとします。

   | 方式 | 支援契約の成立時期 |
   |---|---|
   | 実行確定型（All-in） | 決済が完了した時点 |
   | 目標達成型（All-or-Nothing） | 募集期間の終了時に目標金額を達成した時点 |

3. **目標達成型において目標金額が達成されなかった場合、支援契約は成立せず、支援者に対する請求は行われません。**
4. **支援契約は支援者と出品者との間で成立するものであり、当社は当該契約の当事者ではありません。**
5. 支援者は、支援の申込みにあたり、プロジェクトの内容、リターンの条件、お届け予定時期およびキャンセルの可否を確認するものとします。

### 第18条（決済）

1. 支援の対価は、当社が指定する決済手段により支払うものとします。
2. 目標達成型においては、支援の申込み時にはクレジットカード情報の登録のみを行い、**募集期間の終了時に目標金額を達成した場合に限り、登録されたカードに対して請求を行います。**
3. 前項の請求が、カードの利用限度額の超過、有効期限の切れ、本人認証の失敗その他の事由により行えない場合、当社は支援者に通知のうえ、一定期間内に再度請求を行うことがあります。
4. 前項の再請求によっても決済が完了しない場合、当該支援は無効となり、支援契約は成立しなかったものとして取り扱います。

### 第19条（支援のキャンセル）

1. **実行確定型における支援は、決済完了後にキャンセルすることはできません。**
2. 目標達成型における支援は、募集期間中に限り、当社の定める方法によりキャンセルすることができます。
3. 前二項にかかわらず、次の各号に該当する場合は、第21条に従い返金を行います。
   1. プロジェクトが中止された場合
   2. 当社がプロジェクトを非公開とした場合
   3. その他当社が返金を相当と認めた場合

3. 支援者の情報の誤り、長期不在その他支援者の事由によりリターンが提供できない場合、出品者は再送の義務を負いません。
4. リターンに関する問い合わせおよび苦情は、**出品者に対して**行うものとします。

## 第5章 返金

### 第21条（返金）

1. 当社は、次の各号に該当する場合、支援者に対して返金を行います。

   | 事由 | 返金額 | 決済手数料の負担 |
   |---|---|---|
   | 出品者によるプロジェクトの中止 | 全額 | 出品者 |
   | 当社によるプロジェクトの非公開化 | 全額 | 【要記入：C-6】 |
   | 決済の重複その他当社の事務処理上の誤り | 誤請求分 | 当社 |

2. 返金は、原則として支援時に利用した決済手段に対して行います。
3. **リターンが提供されないこと、またはリターンの内容が期待と異なることを理由とする返金については、支援者と出品者との間で解決するものとし、当社は返金を保証しません。**ただし、当社は必要に応じて当事者間の連絡を仲介することがあります。
4. 返金に関する申出は、リターンのお届け予定時期から【要記入：C-8】以内に行うものとします。
5. 支援者が、返金の対象となる支援に基づいて応援ポイントの付与を受けていた場合、当社は当該ポイントを取り消すことができます。
