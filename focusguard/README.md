# FocusGuard — 終わるまで逃がさない作業強制アプリ(ADHD向け)

「その作業が終わらないとPCが使えなくなる」というアイデアを、**安全に・現実的に**
落とし込んだデスクトップアプリです。

PC 自体は止めません(作業に使うので当然)。代わりに **「離席・別作業・サボり」を
検知し、段階的に強くなる介入** で、宣言したタスクへ強制的に引き戻します。
完了するまで解放されません。

## なぜ「PCを止めない」のか

文字通りPCをロックすると、作業そのものができず本末転倒なうえ、ログインできなく
なる等の事故リスクがあります。FocusGuard は **作業の邪魔(サボり)だけを罰する**
方向に強制力を効かせます。

## 強制力の2本柱

| 仕組み | 内容 |
| --- | --- |
| 離席検知 | キーボード/マウスの無操作が続くと発火(OSのアイドル時間を取得) |
| 定期チェックイン | 操作していても、一定間隔で「進捗を記録」しないと別作業とみなして発火 |

→ 「席を立つ」も「SNSをだらだら見る(=チェックインしない)」も、どちらも捕捉します。

## ペナルティ(だんだん厳しく)

| Lv | 介入 |
| --- | --- |
| 1 | タイトル点滅・やわらかい通知 |
| 2 | 警告音 + ウィンドウ最前面化 |
| 3 | うるさい警告音 + 強制フォーカス |
| 4 | **全画面オーバーレイ**(クリックで戻る) |
| 5 | 全画面 + **タスク名を正確に入力**しないと解除不可 |
| 6 | 全画面 + タスク名入力 + **強制待機カウントダウン**(時間切れ時も発動) |

落ち着いて作業に戻ると、レベルは自動的に下がっていきます。

## 安全策(ロックアウト事故の防止)

- **緊急脱出を常に残す**。ただし衝動的な中断を防ぐため、長い宣言文を正確に入力
  させる "摩擦" を課しています。物理的に閉じ込めることはしません。
- セッション中にウィンドウの×を押しても閉じず、緊急脱出へ誘導します。

## 使い方

```bash
python3 focusguard.py
```

依存ライブラリは不要(標準ライブラリ `tkinter` のみ)。Python 3.8 以降。

> Linux で `tkinter` が無い場合: `sudo apt install python3-tk`
> macOS / Windows の公式 Python には標準で同梱されています。

1. タスク名と制限時間(分)を入力して「開始」
2. 集中して作業。一定間隔で **「進捗を記録(チェックイン)」** を押す
3. 離席・チェックイン放置・時間切れがあると介入レベルが上がる
4. 「✓ タスク完了で解放」を押すと終了

## 設定(`focusguard.py` 冒頭の定数)

| 定数 | 既定 | 意味 |
| --- | --- | --- |
| `CHECKIN_INTERVAL_SEC` | 480 (8分) | チェックイン間隔 |
| `IDLE_LIMIT_SEC` | 90 | 離席判定の基準秒(レベルが上がると短縮) |
| `DECAY_AFTER_SEC` | 30 | ペナルティが自然に下がるまでの猶予 |
| `EMERGENCY_PHRASE` | (宣言文) | 緊急脱出で入力させる文 |

## 動作環境と離席検知

| OS | 離席検知 |
| --- | --- |
| Windows | ✅ `GetLastInputInfo`(追加不要) |
| macOS | ✅ `ioreg HIDIdleTime`(追加不要) |
| Linux | `xprintidle` があれば ✅ / 無ければチェックイン主体で動作 |

離席検知が使えない環境でも、チェックイン方式で強制力は機能します。
