# keirin-lab — 競輪データ収集・特徴量・バックテスト基盤

競輪予想Webツールの土台となるデータパイプラインです。**販売前にモデルの優位性をバックテストで検証する**ことを目的としています。

## 構成

```
keirin/
├── src/keirin/
│   ├── db.py          # SQLite スキーマ定義と接続 (選手・レース・出走・結果・オッズ・天候)
│   ├── features.py    # 特徴量生成 (ライン連携実績・競走得点・バンク相性など)
│   ├── backtest.py    # 買い方戦略の回収率・的中率シミュレーション
│   ├── cli.py         # コマンドラインエントリポイント
│   └── scraper/
│       ├── keirinjp.py  # KEIRIN.JP 出走表・結果スクレイパー (要 requests/bs4)
│       └── weather.py   # 気象庁 過去気象データ取得
└── tests/
```

## セットアップ

コア機能(DB・特徴量・バックテスト)は Python 3.10+ の標準ライブラリのみで動きます。

```bash
cd keirin
python -m keirin.cli initdb          # DB初期化
python -m keirin.cli demo            # サンプルデータ投入 + バックテストのデモ
python -m unittest discover tests    # テスト
```

スクレイパーを使う場合:

```bash
pip install requests beautifulsoup4
```

## 重要な注意 (法務・運用)

- **スクレイピング前に KEIRIN.JP / 各サイトの利用規約を必ず確認すること。** 商用利用は公式データ提供契約が望ましい。`scraper/` はレート制限 (デフォルト3秒/リクエスト) を必ず守る設計。
- 予想情報の提供は合法だが、**車券購入の代行は違法**。
- 「必ず儲かる」等の表現は景品表示法違反。実績 (的中率・回収率) は `backtest.py` の集計をそのまま公開する方針。

## 「仲の良さ」(ライン連携) の数値化

友情そのものは測れないため、以下の代理変数を `features.py` で生成します:

- 同地区・同県・師弟/同期関係のフラグ
- **過去に同ラインを組んだ回数とそのときの連対率** (`pair_line_stats`)
- 番手時の「差し/追従」傾向
