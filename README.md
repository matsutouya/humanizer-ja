# Humanizer JP

日本語AI文章のパターンを除去し、人間が書いたような自然な日本語に書き直すClaude Code Skillです。

[blader/humanizer](https://github.com/blader/humanizer) にインスパイアされ、日本語特有のAI文章メカニズムを根本から再構築しました。

---

## なぜ作ったか

英語AI文章のAI臭さは「統計的に最頻値の語彙を選ぶ」ことから来ます。

日本語AI文章のAI臭さは、**それに加えて3つの日本語固有の構造的要因**から来ます：

1. **敬語による行為主体の消失**（「させていただきます」連発で誰が何をするのか消える）
2. **主語省略による書き手の消失**（「私」「僕」が出てこず、誰が考えているか分からない）
3. **です・ます均質化**（文末がすべて「です」「ます」で揃う）

英語版humanizerをそのまま日本語に適用しても、これらの構造的要因には対応できません。Humanizer JPは、日本語AI文章のメカニズムを根本から理解した上で、40パターンを3階層で修正します。

---

## 特徴

- **40パターン**を3階層で体系化（構造的・語彙的・書式的）
- **6軸の「魂の入れ方」**で人間らしさを注入
- **基調統一ルール**でですます調と常体の混在を防ぐ
- **「、」の打ち方ガイド**で機械的な読点を除去
- **書き手設定（writer-profile.md）**で自分のキャラクターに合わせた文体に変換
- 現代日本語のWeb発信（note・ブログ・SNS）の自然な文体を分析・反映

## 使い方

### 基本の使い方

Claude Codeで以下のように呼び出します：

```
/humanizer-ja

[人間化したい日本語AI文章を貼り付け]
```

### 書き手設定を使う

`writer-profile.md` テンプレートを自分用にカスタマイズして、文体を寄せることができます。

1. `writer-profile.md` をコピーして、自分のアカウント名で保存
2. テンプレートの9項目を自分の言葉で埋める
3. humanizer-ja を使うときに一緒に渡す

```
/humanizer-ja

writer-profile.md の内容に従って、以下の文章を人間化してください：

[書き手設定の内容]

人間化する文章：
[AI文章]
```

ビジネス系・日常系・カジュアル系など、複数のキャラクターを使い分けたい場合は、それぞれ別の設定ファイルを作成してください。

例：
- `writer-profile-business.md`
- `writer-profile-casual.md`
- `writer-profile-formal.md`

## このSkillの守備範囲

**対象：** 日本語の文章のAI臭さを除去すること

**対象外：**
- ハッシュタグの選定
- SNS運用戦略
- 投稿タイミング・頻度
- マーケティング戦略
- 売上アップの提案

このSkillは「AIっぽい日本語を、人間が書いたような日本語に変換する」だけのツールです。

---

## 検出する40パターン

### 階層1：構造的パターン（10個）— 修正すると文章の8割が改善する

1. 敬語による行為主体の消失（「させていただきます」過多）
2. 主語の完全消失
3. です・ます均質化
4. 「〜と考えられます」「〜とされています」逃げ
5. 「〜という点において」「〜という観点から」
6. 結論が最後に来すぎる構造
7. 接続詞の機械的連打（「また」「さらに」「加えて」）
8. 受動態の連発・主語なし断片
9. 体言止めリストの濫用
10. 外向き100%（書き手の存在が消える）

### 階層2：語彙・表現パターン（17個）

11. AI頻出語彙＋過剰強調語（「非常に」「多岐にわたる」など）
12. 意義の水増し（「歴史的な転換点」など）
13. 曖昧な出典（「専門家によると」など）
14. 表面分析（「〜し、〜ており」）
15. PR的・広告的表現
16. 定型の「課題はあるが」
17. be動詞回避（「〜として機能する」など）
18. 否定→肯定の決め台詞
19. 三点セット強制
20. 類義語ローテーション
21. 同語反復を避ける（逆方向の問題）
22. 「まさに〜に他なりません」
23. 過剰な曖昧化
24. 「させていただきます」語尾の連鎖
25. 必ず結論を出す
26. 見せかけの網羅性
27. 機械的な評価語語尾

### 階層3：書式・リズムパターン（13個）

28. 短文連打（ブツ切れリズム）
29. 演出読点
30. 読点の乱打
31. 太字の乱用
32. 太字小見出し＋同内容リスト
33. 絵文字デコレーション
34. チャットボット残滓＋べた褒めトーン
35. 前置き宣言
36. 一定間隔改行
37. 結語の汎用化
38. 弱い主張の語尾を使わない
39. SNSの決め台詞依存
40. 「！」の連打

詳細とBefore/After例は `SKILL.md` を参照してください。

## Before / After 例

### Before（典型的な日本語AI文章）

> 素晴らしいご質問ですね。本日は生成AIの活用についてご説明させていただきます。
>
> 生成AIは、現代のビジネスにおける変革の象徴として、その重要性がますます高まっています。非常に多岐にわたる分野において幅広く活用され、まさに私たちの働き方そのものを大きく変えつつあります。
>
> 課題もありますが、今後の展開が注目されます。本記事がご参考になれば幸いです。

### After（Humanizer JPで変換）

> 生成AIが実務で使えるようになってきたんですが、これ正直、想像以上に効きました。
>
> 特に効くのはメールの下書きと議事録の要約で、30分かかってたものが10分で終わるんですよね。月で20時間くらい浮いた感覚があって、ちょっと怖くなりました。
>
> ただ、コストは去年の3分の1以下になったので、試せない理由はもうないかなと思います。

## 文体分析の参照元

このSkillは、現代日本語のWeb発信（note・ブログ・SNS）で広く使われている自然な文体パターンを観察・分析して作られています。

特に以下のような特徴を抽出しました：

- 接続助詞ネットワーク（「〜なんですが」「〜なんですよね」「〜ので」）
- 弱い主張の語尾（「〜と思います」「〜気がします」）
- 読者への呼びかけ（「〜じゃないですか」）
- 口語強調（「結構」「かなり」「めちゃくちゃ」）
- 話し言葉と書き言葉の自然な混合

これらは特定の書き手の文体ではなく、**現代日本語のWeb発信で読まれているコンテンツに広く見られるパターン**です。
