# 詐欺に遭ったときにやること完全版

## 初動60分・相談機関カタログ・回収の全手順

---

> **この記事は無料部分だけで「今日やるべきこと」が終わる設計にしています。**
>
> いま被害の最中にいる人は、購入せず無料部分だけ読んで、書いてあることを今すぐ実行してください。それで口座凍結と追加送金の停止までは間に合います。
>
> 有料部分は「そのあと、どう回収するか」「どこに相談するか」「二度と遭わないためにどう組み替えるか」を扱っています。冷静になってから読むもので、緊急時に読むものではありません。

---

## この記事について

詐欺の対処法は、ネット上に断片的な情報が大量にあります。ただ、そのほとんどが「警察に相談しましょう」「弁護士に相談しましょう」で終わっていて、実際に電話をかける段階で手が止まります。

どこに、何時に、どの順番で、何を言うのか。それが書かれていない。

この記事は、そこを埋めるために作りました。電話をかけるときの言い方、持っていく書類、相談機関ごとに何ができて何ができないか、どの期限を過ぎると権利が消えるか。読みながらそのまま実行できる形にしています。

全体は14章と巻末の書式集で構成しています。上から順に読む必要はありません。第7章の相談機関カタログと第11章の手口別マニュアルは、必要なときに引く辞書として使ってください。

> 本記事は一般的な対処の流れと制度の解説です。個別の事案の法的判断は弁護士または各相談機関に確認してください。制度・窓口・費用は改定されることがあるので、実行前に公式情報での確認をおすすめします。

# 【無料】序章｜まず、この1ページだけ実行してください

購入する前に、これだけやってください。ここは無料で読める範囲に置いています。

## 今すぐやる5つ

**1. 追加の送金を止める**

何を言われても、もう1円も出さない。「手数料を払えば戻る」「税金を先に納めれば出金できる」「あと一回だけ入金すれば全部解決する」。これらは全部、被害額を膨らませるための言葉です。ここで止められるかどうかで、被害が100万で終わるか1,000万になるかが決まります。

**2. 振込先の金融機関に電話して口座凍結を依頼する**

自分の銀行ではありません。**振り込んだ先の銀行**です。ここを間違える人が本当に多い。

銀行名と支店名は振込明細に載っています。代表番号にかけて「詐欺被害に遭ったので口座凍結をお願いしたい」と最初に言えば、担当部署に回ります。

夜間・休日なら、カードの盗難紛失窓口が24時間つながります。そこから緊急連絡してください。

**3. カード・電子マネー・暗号資産なら、各事業者へ即連絡**

クレジットカードはカード裏面の番号へ。ギフト券は発行元へ。暗号資産は使った取引所へ。**ギフト券のコード番号をまだ相手に伝えていないなら、止められる可能性がかなり残っています。**

**4. 110番、または最寄りの警察署**

被害届の受理番号があると、その後の銀行やカード会社とのやり取りが一気に速くなります。

**5. 証拠を保存してから、ブロックする**

やり取りは相手が消す前に保存してください。ブロックすると履歴が見られなくなるサービスがあります。順番は保存が先です。

## なぜ「今すぐ」なのか

詐欺の設計は「入金されたら即抜く」前提で作られています。振込先の口座はたいてい他人名義で、入った瞬間に別口座へ飛ばされるか、ATMで現金化されます。

そして、振り込め詐欺救済法で戻ってくるのは**凍結した時点で口座に残っていた金だけ**です。全額抜かれたあとに凍結しても、分配されるのは0円になる。

「明日の朝いちで銀行に行こう」で、間に合わなくなる。数時間の差です。

ここまでが無料部分です。上の5つを実行してから、続きを読んでください。

# 第1章｜大原則：結果を決める4つの変数

## 回収できるかどうかは、この順番で決まる

詐欺に遭ったあとの結果を決める要素は、優先度の高い順にこの4つです。

| 順位 | 変数 | 中身 |
|---|---|---|
| 1 | **時間** | 気づいてから最初のアクションまでの時間 |
| 2 | **特定** | 相手の氏名・住所・口座名義が分かっているか |
| 3 | **資力** | 相手に金または差押えできる財産が残っているか |
| 4 | **証拠** | やり取り・送金記録・契約書が残っているか |

多くの人が逆から手をつけます。まず証拠を整理して、次に法律を調べて、弁護士を探して、それから動く。

この順番でやると、整理している間に口座は空になります。証拠が完璧でも、相手に金がなければ回収額はゼロです。逆に、証拠が多少雑でも初動が速くて相手が特定できていれば、話し合いだけで返ってくることがある。

**法的な正しさは4番目です。** ここを取り違えないでください。

## 「調べてから動く」が敗着になる理由

被害に気づいた人がまずやるのは検索です。これは自然な反応ですが、詐欺の設計はそのタイムラグを織り込んでいます。

被害者が「これ詐欺かも」と思ってから確信するまで、平均で数時間から数日かかります。半信半疑の状態では動けない。「もしかしたら本当に戻ってくるのかも」と思ってしまう。その心理的な猶予が、詐欺側の逃走時間です。

だから判断基準はこうしてください。**確信がなくても、疑った時点で凍結依頼をかける。**

万が一それが正当な取引だった場合でも、凍結は解除されます。相手に迷惑をかけることはあっても、取り返しはつく。逆はつきません。

## 回収可能性の自己診断

自分の案件がどのランクにあるかを先に把握しておくと、どこまでコストをかけるべきかの判断ができます。以下の10問に答えてください。

**Q1.** 送金してから何時間経ったか
- 3時間以内 → 5点／24時間以内 → 4点／3日以内 → 2点／1週間以内 → 1点／それ以上 → 0点

**Q2.** 相手の本名を知っているか
- 本名と住所を知っている → 5点／本名だけ知っている → 3点／口座名義だけ分かる → 2点／何も分からない → 0点

**Q3.** 相手に会ったことがあるか
- 何度も会っている → 4点／一度会った → 3点／ビデオ通話のみ → 1点／文字だけ → 0点

**Q4.** 送金手段は
- 国内銀行振込 → 4点／クレジットカード → 4点／現金手渡し → 2点／ギフト券 → 1点／暗号資産 → 1点

**Q5.** 相手は法人か
- 実体のある法人（登記を確認できた） → 4点／登記はあるが実体不明 → 2点／個人 → 2点／不明 → 0点

**Q6.** やり取りの記録が残っているか
- 全部残っている → 3点／一部残っている → 2点／消された → 0点

**Q7.** 相手はまだ連絡が取れるか
- 取れる → 3点／既読はつく → 2点／音信不通 → 0点

**Q8.** 相手に財産があると分かっているか
- 不動産や事業を持っている → 4点／勤務先を知っている → 3点／不明 → 0点

**Q9.** 被害額は
- 50万円未満 → 1点／50〜300万 → 2点／300万以上 → 3点（金額が大きいほど費用をかける合理性がある）

**Q10.** 他にも被害者がいるか把握しているか
- 複数人いて連絡が取れる → 3点／いるらしいが不明 → 1点／自分だけ → 1点

**判定**

| 合計 | ランク | 現実的な見通しと打ち手 |
|---|---|---|
| 30点以上 | A | 回収可能性が高い。すぐ本人接触＋書面確保。弁護士費用をかける価値が十分ある |
| 22〜29点 | B | 交渉と法的手続きで取れる余地がある。仮差押えの検討を含めて弁護士へ |
| 14〜21点 | C | 相手の特定が鍵。弁護士会照会など特定手段に投資する価値がある |
| 7〜13点 | D | 刑事ルート（被害届・告訴）と口座凍結の分配に賭ける。民事費用は慎重に |
| 6点以下 | E | 回収は厳しい。二次被害の防止と再発防止に切り替えるほうが合理的 |

Eランクだからといって何もしないのではありません。**被害届は出してください。** 同じ口座に他の被害者がいれば分配の対象になりますし、捜査の端緒として積み上がります。

ただし、Eランクの案件に高額な調査費を払うのは、二次被害の入口です。この判定はそこの歯止めとして使ってください。

# 第2章｜最初の60分（送金手段別・完全フロー）

自分がどの手段で金を渡したかで、最初に電話する先が変わります。該当するものだけ読んでください。

## 2-1. 銀行振込

### やること

振込先の金融機関に電話して口座凍結を依頼する。

### 電話のかけ方（そのまま使えるスクリプト）

代表番号または最寄り支店にかけて、最初にこう言ってください。

> 「詐欺の被害に遭いました。御行の口座に振り込んでしまったので、口座凍結の手続きをお願いしたいです。担当の部署におつなぎください」

「詐欺被害」「口座凍結」の2語を最初に出すのがコツです。この2語で振り込め詐欺救済法の担当窓口に回ります。用件を説明しようとして経緯から話し始めると、一般窓口で時間を使うことになる。

つながったら、この順で伝えます。

1. 自分の氏名・生年月日・連絡先
2. 振込日時（何月何日の何時何分）
3. 振込金額
4. 振込元の金融機関・支店・口座番号
5. 振込先の口座番号と口座名義（カタカナ表記のまま）
6. 詐欺だと判断した理由（簡潔に。「投資と言われて振り込んだが出金できない」程度で十分）
7. 警察に届け出済みかどうか、届出番号があれば伝える

### 時間帯別の動き

| 気づいた時間 | やること |
|---|---|
| 平日9:00〜15:00 | 支店に直接電話。最速で動く |
| 平日15:00〜17:00 | 支店の営業時間外だが本部窓口が対応する場合あり。まず電話 |
| 夜間・休日 | カードの盗難紛失窓口（24時間）から緊急連絡。翌営業日の朝一番でもう一度 |
| 深夜 | 110番を先に。銀行は翌朝一番 |

夜間の緊急連絡だけでは凍結まで進まないことがあります。**必ず翌営業日の朝、もう一度かけ直してください。** 「昨夜連絡した件です」と伝える。

### 振り込め詐欺救済法の仕組みと限界

正式名称は「犯罪利用預金口座等に係る資金による被害回復分配金の支払等に関する法律」です。流れはこうなります。

1. 金融機関が口座を凍結（取引停止）
2. 預金保険機構のウェブサイトで公告される（名義人の権利を消滅させる手続き。60日以上の期間）
3. 被害者からの支払申請の受付（30日以上の期間）
4. 残高を被害額の比率で按分して分配

ここで押さえておくべき限界が3つあります。

**限界1：戻るのは凍結時点の残高だけ。** 抜かれたあとなら0円です。

**限界2：他の被害者と分け合う。** 同じ口座に5人の被害者がいて残高が100万円なら、被害額の比率で割ります。

**限界3：残高が1,000円未満だと分配手続きの対象外になる。** 実務上、これに該当するケースはかなり多い。

つまりこの制度は「間に合えば強い、間に合わなければ何もない」という性質です。だから速度なんです。

### 同時にやること

自分の取引銀行にも連絡してください。凍結の権限は相手の銀行にありますが、自分の銀行が相手行に照会を入れてくれる場合があります。また、自分の口座情報が漏れている可能性があるなら、キャッシュカードの再発行やネットバンキングのパスワード変更も同時に。

## 2-2. クレジットカード

### やること

カード会社に電話して、決済の取消（チャージバック）を申し出る。あわせてカード番号の変更・再発行。

### 電話のかけ方

カード裏面の番号へ。

> 「詐欺サイトで決済してしまいました。チャージバックの手続きをお願いしたいです。あわせてカード番号の変更もお願いします」

### チャージバックの仕組み

国際ブランド（Visa、Mastercard、JCBなど）のルールに基づく手続きで、加盟店に対して代金を差し戻すものです。カード会社が加盟店の決済代行会社に異議を申し立てて、代金が戻る流れになります。

使える主な類型。

- 商品・サービスが提供されなかった
- サイトが実在しなかった、事業者と連絡が取れない
- 説明と著しく異なるものが提供された
- 身に覚えのない決済（不正利用）
- 解約したのに請求が続いている

### 期限に注意

ブランドと理由によって異なりますが、**おおむね120日程度が目安**です。取引日または商品の到着予定日を起算点とします。長期の役務提供では例外的に伸びるケースもありますが、原則として早いほうがいい。

引き落とし日をまたぐと手続きが増えます。請求が確定する前に連絡が入っているのが理想です。

### 割賦販売法の「支払停止の抗弁」との違い

混同されやすいので分けて整理します。

| | チャージバック | 支払停止の抗弁 |
|---|---|---|
| 根拠 | 国際ブランドのルール | 割賦販売法30条の4など |
| 対象 | 一括払いも含む | 分割払い・リボ払い・個別クレジット |
| 金額要件 | なし | 支払総額4万円以上（リボは3万8,000円以上） |
| 効果 | 決済そのものを取り消す | 残債の支払いを止める |
| 申立先 | カード会社 | カード会社 |

**一括払い（マンスリークリア）は割賦販売法の支払停止の抗弁の対象外です。** ここは勘違いが多い部分。一括払いならチャージバックのルートで交渉することになります。

### 不正利用の場合

自分が決済していない（カード情報を盗まれた）ケースは、カード会社の盗難保険が適用されます。多くの場合、**届出日から遡って60日以内**の被害が補償対象です。ここも期限があるので、明細は月1回必ず見てください。

## 2-3. デビットカード・プリペイドカード

デビットは即時に口座から引き落とされるので、クレジットより回収が難しくなります。それでも発行元の銀行に不正利用として申告してください。デビットにも補償制度を設けている銀行があります。

プリペイドはチャージ残高が残っていれば止められる可能性があります。発行会社へ。

## 2-4. 電子マネー・ギフト券・コード決済

### やること

発行元に電話して利用停止を依頼する。

対象になるのは、Amazonギフトカード、Appleギフトカード、Google Playギフトカード、各種プリペイド型電子マネーなど。コンビニで買わされたパターンです。

### 分岐点は「コードを伝えたかどうか」

**まだ番号を相手に伝えていないなら、止められる可能性がかなり高い。**

購入したコンビニのレシートと、カード本体を持って発行元のカスタマーサポートに連絡してください。**レシートは絶対に捨てないこと。** 購入証明がないと手続きが進みません。

番号を伝えてしまったあとでも、まだ使われていなければ止まることがあります。ここも数時間の差です。

### コード決済（PayPay、楽天ペイなど）

運営の問い合わせ窓口に「不正利用・詐欺被害」として申告します。送金機能を使わされた場合、相手のアカウントが凍結される可能性があります。

## 2-5. 暗号資産（仮想通貨）

### やること

使った取引所に連絡。送金先が国内取引所のアドレスなら、そこにも連絡。

### 記録すべき情報

- 送金トランザクションのハッシュ（TXID）
- 送金先アドレス
- 送金日時と数量
- 使用した取引所名とアカウント情報

### 現実的な見通し

正直に書きますが、暗号資産の回収率は他の手段よりかなり低いです。海外の匿名性が高いウォレットやミキシングサービスに飛ばされると、ブロックチェーン上で追跡はできても、差し押さえる相手がいない。

ただし、送金先が国内の取引所や大手海外取引所のアドレスに紐づいている場合は、凍結できることがあります。取引所は本人確認をしているので、そこにたどり着けば相手が特定できる。

**捜査機関に持ち込む価値はあります。** 近年は国際的な追跡協力の枠組みが機能し始めていて、時間はかかっても戻った事例が出ています。

### 相談先

使った取引所のサポート、各都道府県警のサイバー犯罪相談窓口、そして日本暗号資産等取引業協会（JVCEA）の相談窓口。

## 2-6. 携帯キャリア決済

キャリア（ドコモ、au、ソフトバンク、楽天）の窓口に不正利用として申告します。上限額の設定を0円に変更することも同時に依頼してください。

## 2-7. 現金手渡し・宅配便での送付

### 宅配便で送ってしまった場合

**配達完了前なら止められます。**

追跡番号を持って、すぐに配送業者に連絡してください。「詐欺被害なので配送を止めてほしい、差出人に戻してほしい」と伝える。日本郵便なら「配達差止」という手続きがあります。

同時に110番。受け取り役が指定した住所は、たいてい空き物件やホテル、レンタルスペース、宅配ボックスです。警察が張れば現行犯逮捕になる可能性がある。

### 手渡しの場合

相手の顔を見ている、これは大きなアドバンテージです。第4章に進んでください。

## 2-8. 電話をかける順番の整理

複数該当する場合の優先順です。

1. 銀行（凍結が時間勝負なので最優先）
2. 110番または警察署
3. カード会社・ギフト券発行元・取引所
4. 配送業者（送付中の荷物がある場合は1番目でもいい）
5. 自分の取引銀行

**同時進行で構いません。** 家族がいるなら分担してください。ひとりで順番にやると、後ろのほうが翌日に回ります。

# 第3章｜証拠の保全（電話をかけながら並行で）

## 消える順番を知っておく

被害が発覚すると、相手は証拠を消しにかかります。消える順番はだいたい決まっています。

| 消える速さ | 対象 |
|---|---|
| 数時間 | SNSアカウント、LINEのブロック＆削除、専用サイト |
| 1〜3日 | LP・セールスページ、決済ページ |
| 1週間 | 会社概要ページ、ドメイン |
| 残りやすい | 振込明細、通帳、カード明細、自分側に保存済みのデータ |

つまり、**相手側にしかないデータから先に取る**。これが優先順位です。

## 保存リスト

チェックしながら進めてください。

- [ ] LINE・Telegram・Instagram・X・Facebook などのやり取り全文
- [ ] 相手のアカウント名・ID・プロフィールURL・アイコン画像
- [ ] 相手が使っていた表示名の変遷（変えている場合が多い）
- [ ] グループチャットの参加者一覧（サクラの特定に使える）
- [ ] 振込明細、ATM利用控え、通帳の該当ページ
- [ ] 振込先の口座番号・支店名・口座名義（カタカナのまま正確に）
- [ ] 電話番号と通話履歴の日時
- [ ] 契約書・申込書・利用規約（PDFで保存）
- [ ] サイトのURL全部とページ全体のスクリーンショット
- [ ] 相手を知ったきっかけの広告のスクショ
- [ ] 相手が送ってきた画像・書類（偽の運用画面、偽の証券口座、偽の身分証など）
- [ ] 送金依頼のメッセージ（「ここに振り込んで」という文言そのもの）
- [ ] 自分が作った時系列メモ

## 具体的な保存手順

### LINE

トーク画面右上のメニュー → 設定 → トーク履歴を送信、でテキストファイルとして書き出せます。**スクショと両方**取ってください。テキストは全文が残る、スクショは画面の見た目が残る。役割が違います。

画像や動画はトーク内から個別に保存が必要です。LINEの画像には保存期間があるので、これは早めに。

Keep（キープ）に移す方法もありますが、アカウント自体が使えなくなるリスクを考えると、端末とクラウドに落としておくほうが安全です。

### Webページ

ブラウザの「印刷 → PDFとして保存」でページ全体を残せます。URLと日付がフッターに入る設定にしておくと証拠価値が上がります。

消えたページはWayback Machine（web.archive.org）に残っていることがあります。逆に、**まだ生きているページを自分でWayback Machineに保存しておく**という手もあります。第三者のサーバーに保存日時つきで残るので、あとから「自分が改ざんした」と言われにくい。

### スクリーンショット

**日時が写り込む形**で撮ってください。スマホなら画面上部の時刻表示ごと。あとから「いつのやり取りか」を示す材料になります。

### 録音

これから相手と話す予定があるなら、録音してください。

**自分が参加している会話の録音は違法ではありません。相手の同意も不要です。** 民事訴訟でも証拠として採用されます。

無断録音が問題になるのは、自分が参加していない会話を盗聴した場合や、著しく反社会的な手段で取得した場合です。当事者録音は該当しません。

電話ならスマホの通話録音アプリ、対面ならボイスメモをポケットに入れておく。

## 時系列メモのフォーマット

これは必ず作ってください。警察でも弁護士でも、最初に聞かれるのは時系列です。口頭で説明しようとすると必ず混乱するので、紙で出す。

| 日付 | 出来事 | 金額 | 証拠 |
|---|---|---|---|
| 2026/3/1 | Instagramで〇〇からDM | | スクショ① |
| 2026/3/3 | LINE交換、投資の話を受ける | | トーク履歴 |

A4一枚に収まるならそれでいい。証拠の番号と対応させておくと、そのまま提出資料になります。

## やってはいけない証拠の扱い

- **加工しない。** トリミングだけでも「改ざんの可能性」を疑われます。マスキングが必要でも原本は必ず残す
- **証拠を取り終える前にブロックしない**
- **相手に「証拠は全部押さえた」と言わない**（消しにかかります）
- **元データを消さない。** クラウドに上げても端末から消さない
- **SNSで晒さない。** 名誉毀損で反撃される材料になり、示談交渉でも不利になります

# 第4章｜相手が特定できるなら、最速で会いに行く

ここがこの記事の核心です。

## 前提：これは全員向けではない

匿名の海外グループが相手なら、この章は使えません。ここが効くのは**相手が実在の人物・法人で、住所や勤務先が分かっている場合**です。

具体的にはこういうケース。

- 知人・友人・親族からの投資話
- ビジネスパートナーの持ち逃げ、案件の飛ばし
- 取引業者の前払い金の未履行
- SNSで知り合ったが実際に会ったことがある相手
- リフォーム・工事の前払い
- 事業譲渡・M&A絡み
- 貸したまま返ってこない金

このパターンなら、最も回収率が高い手段は法的手続きではありません。**気づいた当日に本人のところへ行くこと**です。

## なぜ速いほど効くのか

理由は3つあります。

### 理由1：相手の金がまだ残っている

詐欺をやる人間は、入った金をすぐ使います。ギャンブル、次の案件の穴埋め、生活費、遊興費。1週間経てば消えています。

「今は手元にない」は本当のことが多い。だから初日に行く。

### 理由2：相手がまだ逃げる準備をしていない

詐欺師は、被害者が気づいてから逃走準備に入ります。住所を変え、電話番号を捨て、SNSを消す。ここに数日から数週間かかります。

気づいた直後なら、まだそこにいる。1か月後には、もういません。

### 理由3：他の被害者より先に着ける

詐欺は同じ手口で複数人からやっています。返せる原資には限りがある。

このとき詐欺師が取る行動は決まっていて、**最初に来た人には返して黙らせ、後から来た人は無視する**。騒がれるリスクを一人分だけ潰しておくという計算です。

つまり、動くのが遅いほど「返してもらえる列」の後ろに並ぶことになる。

## 誰と行くか

**ひとりで行かないでください。**

理由は2つあります。相手が逆上する可能性があること。そして、相手が後から「脅された」と言い出す可能性があること。第三者がいるだけで両方のリスクが下がります。

同行者は、友人、家族、同じ被害に遭った人、誰でも構いません。ただし、**その場で怒鳴るタイプの人は連れて行かない**。一人が冷静なら成立しますが、二人とも熱くなると恐喝の構図になります。

理想は、こちらが話す役、同行者が記録する役、と分けることです。

## 行く前のチェックリスト

- [ ] ボイスメモを起動しておく（会う直前ではなく、建物に入る前から）
- [ ] 同行者を1人確保した
- [ ] 要求を1行で決めた
- [ ] 送金の証拠（振込明細）をプリントして持った
- [ ] 念書のひな形をプリントして持った（巻末に掲載）
- [ ] ペンを2本持った
- [ ] 相手の言い訳パターンへの返しを決めた
- [ ] 自分の帰る時間を決めた（長時間の押し問答は監禁と誤解される）
- [ ] 家族か友人に「今からどこに行くか」を伝えた
- [ ] 感情的にならないと決めた

## 要求は1行で

これがいちばん重要です。

> 「〇月〇日に振り込んだ〇〇円を、いつまでに、どう返すのか」

これだけ。怒りをぶつけに行くのではなく、返済の約束を取りに行く。目的を1行にしておかないと、必ず話が逸れます。

詐欺師は話を逸らすのが上手いです。「自分も被害者だ」「あの案件は今こういう状況で」「もう少しで解決する」。全部、時間を稼ぐための話です。

こちらが返すのは1つだけ。

> 「わかりました。それで、いつ、いくら返せますか」

これを何度でも繰り返す。感情を乗せず、同じ質問を返す。相手は必ず折れるか、逃げるかのどちらかになります。どちらでも構いません。折れれば書面が取れる、逃げれば「返す気がない」ことがはっきりして次の手に進めます。

## 言い訳9パターンと切り返し

現場で必ず出てくるものです。事前に読んでおいてください。

**1. 「今は手元にない」**
→ 「では、いつなら用意できますか。日付を決めましょう」

**2. 「もう少し待てば戻ってくる」**
→ 「その根拠を書面でいただけますか。何がどうなれば戻るのか、日付と一緒に」

**3. 「自分も騙された、自分も被害者だ」**
→ 「わかりました。では一緒に被害届を出しに行きましょう。今から警察へ行けますか」（本当に被害者ならこれに応じます。応じないなら嘘です）

**4. 「投資だからリスクがあると説明した」**
→ 「〇月〇日のLINEで『元本保証』と書いてありますね。これはどう説明されますか」（証拠を出す）

**5. 「訴えるなら訴えればいい」**
→ 「そうします。その前に、今日いくら返せるかだけ確認させてください」（挑発に乗らない）

**6. 「弁護士に任せてある。今後は弁護士を通してくれ」**
→ 「弁護士の先生のお名前と事務所を教えてください」（本当なら教えます。教えられないなら嘘です）

**7. 「他の人にも返していない、あなただけ特別扱いはできない」**
→ 「他の方の連絡先を教えてください。一緒に対応します」（詐欺師がいちばん嫌がる展開です）

**8. 「そんなに言うなら分割で」**
→ 乗ってください。ただし**初回の入金額を大きく**設定する。詳細は後述

**9. 「もう一度投資すれば全部取り戻せる」**
→ これは追加被害の勧誘です。その場で打ち切って帰る

## 越えてはいけない5つの法的ライン

ここは真面目に読んでください。被害者側が加害者になるケースが、現実にあります。

| 行為 | 成立し得る罪 |
|---|---|
| 殴る、突き飛ばす、物を壊す | 暴行罪・傷害罪・器物損壊罪 |
| 「払わないとどうなるか分かってるな」「会社にバラすぞ」 | 恐喝罪 |
| 帰らせない、部屋やクルマに留め置く | 監禁罪 |
| 相手の物を勝手に持ち帰る（担保のつもりでも） | 窃盗罪 |
| 深夜に何度も押しかける、家族に繰り返し連絡する | 住居侵入罪・ストーカー規制法・強要罪 |

**日本の法律は自力救済を認めていません。自分の金だからといって、実力で取り返すのは違法です。**

そして詐欺師側はこのラインを知っています。こちらを刑事事件に持ち込んで、被害額を相殺しようとしてくる。録音していたのが相手だけという状況が最悪です。

やるのは、あくまで**冷静な催告**です。声を荒げないほうが、実は相手は焦ります。淡々と数字と日付だけを詰めてくる相手のほうが、怒鳴る相手より怖い。

## その場で必ず取る書面

口約束で帰らないでください。紙を1枚もらうだけで、その後の展開が変わります。

### 何を書いてもらうか

- 作成日
- 相手の氏名（**自署**）・住所・生年月日
- 「〇年〇月〇日に受領した金〇〇円について、返還債務があることを認める」という一文
- 返済の期限と方法
- 分割なら回数・各回の金額・支払日・振込先
- 期限の利益喪失条項（一度でも遅れたら残額を一括で払う、という条項）
- 相手の押印（あれば良い。なくても有効）

手書きで構いません。コンビニのレシートの裏でも法的には成立します。書いてもらったらその場でスマホで撮って、クラウドに上げてください。原本は自分が持ち帰る。

**住所は本人確認書類で確認してください。** 「免許証を見せてもらえますか」と言って、写真を撮る。ここを口頭の申告だけで済ませると、後で訴状が届きません。

### この紙が持つ3つの意味

**意味1：相手の氏名と住所が確定する。** 民事訴訟は相手の住所が分からないと起こせません。訴状が送達できないからです。この一点だけでも紙を取る価値があります。

**意味2：債務承認になる。** 時効の進行がリセットされます（民法152条・承認による時効の更新）。

**意味3：「詐欺ではなく投資の失敗だった」という言い逃れを潰す。** 返還債務を認めた以上、後から「あれは元本保証のない投資だった」とは言えなくなる。

### さらに強い形：公正証書

書面に応じる相手なら、次の提案をしてみてください。

> 「公証役場で正式な書類にしましょう。そのほうがお互い安心なので」

**強制執行認諾文言付きの公正証書**にできれば、裁判をしなくても差押えができます。これは非常に強い。

費用は目的の価額によりますが、100万円で5,000円、500万円で11,000円、1,000万円で17,000円程度（公証人手数料令）。相手と一緒に公証役場へ行く必要があります。

応じない相手のほうが多いですが、提案する価値はあります。応じるかどうかで相手の本気度も測れる。

## 分割の設計

分割に応じる場合、設計を間違えると回収できません。

**原則1：初回を大きく。** 「今日いくら払えますか」で当日中に取れる分を取る。分割は残額に対して組む。1円も入らないまま分割の約束だけしても、たいてい1回目から遅れます。

**原則2：回数を伸ばしすぎない。** 24回、36回にすると相手は必ず途中で消えます。長くて12回。

**原則3：期限の利益喪失条項を入れる。** 「1回でも支払いを怠ったときは、期限の利益を失い、残額を直ちに一括して支払う」。これがないと、遅れるたびに催促し直すことになります。

**原則4：振込先を自分の口座に指定する。** 手渡しにすると毎回会う羽目になり、記録も残りません。

**原則5：連帯保証人を立てられないか聞く。** 家族や共同事業者。応じることは少ないですが、聞く価値はある。

## 会えなかった場合のB案

いない、居留守を使われる、住所が違った。この場合。

- 郵便受けに「〇月〇日に伺いました。ご連絡ください」というメモを入れる（脅迫的な文言は絶対に書かない）
- その日のうちに内容証明郵便を発送する
- 表札・郵便物・電気メーターの動きから居住の実態を確認する（写真を撮る。ただし敷地内に無断で入らない）
- 勤務先が分かっているなら、勤務先への直接訪問はいったん保留する（やり方を誤ると威力業務妨害や名誉毀損になります。弁護士と相談してから）

住所が違った時点で、この案件のランクは下がります。第5章の特定手段に切り替えてください。

# 第5章｜相手が特定できないときの、特定の手段

住所が分からないと訴訟は起こせません。だから「特定」は法的手段の入口の条件です。ここに投資する価値がある案件かどうかは、第1章の診断で判断してください。

## 5-1. 弁護士会照会（弁護士法23条の2）

いちばん実用的な手段です。

弁護士が所属弁護士会を通じて、公務所や企業に照会をかける制度。これで取れる可能性があるもの。

- 銀行に対して：口座名義人の住所・氏名・生年月日、取引履歴
- 携帯電話会社に対して：電話番号の契約者情報
- 運送会社に対して：荷物の受取人情報
- プロバイダに対して：契約者情報

**注意点。** 回答は法律上の義務とされていますが罰則がなく、拒否されることがあります。特に近年は個人情報保護を理由に回答しない金融機関もある。それでも銀行口座については応じるケースが多いです。

弁護士に依頼しないと使えません。費用は1件あたり数千円〜1万円程度の実費に、弁護士の手数料が乗ります。

## 5-2. 発信者情報開示

SNSやサイトの運営者に対して、投稿者の情報開示を求める手続きです。

2022年10月から「発信者情報開示命令」という新しい裁判手続きが始まって、以前より手続きが1本化されました。それでも、詐欺のケースでは名誉毀損のケースより使いにくい。「権利侵害の明白性」の立証が必要になるからです。

海外事業者（Meta、Xなど）が相手だと、時間と費用がかさみます。被害額との見合いで判断してください。

## 5-3. 口座名義からの追跡

振込先の口座名義は必ず分かっているはずです。ここが最大の手がかりになります。

**法人名義なら**、法務局で登記事項証明書を取ってください。誰でも取れます（1通600円、オンラインなら安い）。代表者の氏名と住所が載っています。これだけで訴訟が起こせるケースがある。

法人名義の口座に振り込ませる詐欺は意外と多く、しかも実在の休眠会社を買い取っているパターンがあります。登記から役員の変更履歴を追うと、実際の運営者が見えることがあります。

**個人名義なら**、弁護士会照会のルートです。

## 5-4. 携帯電話番号からの追跡

弁護士会照会で契約者情報を取ります。ただし飛ばし携帯（他人名義）の場合は行き止まりになります。

## 5-5. 暗号資産のトレース

ブロックチェーン上の資金移動は公開情報なので、追跡自体は可能です。専門の分析会社もあります。

最終的に国内取引所に着金していれば、そこから特定できる可能性がある。捜査機関のほうがこのルートは強いので、サイバー犯罪相談窓口に持ち込むのが現実的です。

## 5-6. 他の被害者を探す

見落とされがちですが、これが有効なことがあります。

同じ手口の被害者が複数いれば、誰かが相手の本名や住所を知っている可能性がある。SNSで手口の名前やアカウント名を検索すると、被害者のコミュニティが見つかることがあります。

ただし、**「被害者の会」を名乗るグループには二次被害の入口が混ざっています。** 金銭を要求してきたり、特定の業者を紹介してくるグループには近づかない。情報交換だけにとどめてください。

## 5-7. 刑事ルートに乗せる

民事で特定できない場合でも、警察の捜査なら特定できることがあります。捜査関係事項照会は弁護士会照会より強力です。

**ただし、捜査状況は被害者に開示されません。** 犯人が検挙されたことは通知されますが、その前の段階の情報は基本的に来ない。「警察に出したから安心」ではなく、民事は民事で並行させる必要があります。

検挙されれば、そこから示談交渉のルートが開きます。実務上、刑事事件化してから返ってくるパターンは少なくありません。

# 第6章｜二次被害：ここで人生の残りを削る

被害の中で、本体の被害より深刻になりやすいのがここです。

## 詐欺に遭った人は、もう一度やられる

理由ははっきりしています。**被害者の情報が名簿として流通するからです。**

「一度払った人」は「また払う人」として、名簿業者の間で高値で取引されます。だから被害の直後から、こういう連絡が来始めます。

- 「詐欺被害の回収を専門にしています」というSNSのDM
- 「必ず取り返します」と書いてある調査会社のサイト広告
- 「弁護士と提携しています」という自称コンサルタント
- 「あなたの被害を国が補償する制度があります」という電話
- 「以前の被害を回復する権利がある。手数料を先に払えば返金される」というメール
- 「あなたの名簿を削除してあげる」という業者（名簿削除詐欺）
- 「あなたの代わりに購入権利を買い取りたい」という劇場型（複数人で役を演じる手口）

全部、二次被害の入口です。

## 着手金ビジネスの構造を解剖する

いちばん多いのが、着手金だけ取って何もしないパターンです。構造を分解します。

**ステップ1。** 「調査費・着手金」として20万〜50万円を先に受け取る

**ステップ2。** 実際の業務は「相手に連絡を試みる」で終わる

**ステップ3。** 2〜4週間後に「調査しましたが、相手の特定に至りませんでした」と報告

**ステップ4。** 契約書に「調査を行う」としか書いていないので、業務は履行済みという扱いになる

**ステップ5。** 着手金は返らない

これが巧妙なのは、**嘘をついていないこと**です。「必ず取り返す」と口頭では言うが、契約書には書かない。契約書上の債務は「調査の実施」なので、それは履行している。だから民事で争っても勝ちにくい。

さらに、探偵業者や調査会社が報酬を得て法律事務（交渉・請求・和解）を行うのは、**弁護士法72条違反（非弁行為）**にあたる可能性があります。つまり、そもそも合法的に交渉できない相手に交渉を頼んでいることになる。

消費者庁と国民生活センターは、この「詐欺被害の回復をうたう二次被害」について繰り返し注意喚起を出しています。

## 払っていい相手／払ってはいけない相手

金を一切払うなという話ではありません。**信頼できる筋に払うのは、むしろ正しい投資になり得ます。** 問題は見分け方です。

### 払っていい相手の条件（全部満たすこと）

- [ ] **弁護士である。** 日本弁護士連合会または各弁護士会の名簿で、氏名・登録番号・所属会を確認できる。サイトの「弁護士監修」ではなく、担当する本人が弁護士かどうか
- [ ] 着手金の額と、回収できなかった場合にどうなるかを、こちらが聞く前に説明してくる
- [ ] **「回収は難しいかもしれない」と正直に言う。** 見込みの低さを先に伝えてくる
- [ ] 費用の内訳が書面で出る（着手金・報酬金・実費・日当が分かれている）
- [ ] 契約を急がせない。「持ち帰って検討します」に応じる
- [ ] 事務所の所在地に実体がある
- [ ] 委任契約書を交わす

### 払ってはいけない相手の特徴（1つでも該当したら退く）

- 「必ず」「100%」「絶対に取り返します」と言う
- SNSのDM、YouTubeのコメント欄、掲示板から接触してきた
- 会社の所在地がバーチャルオフィスだけ
- 「今日中に決めてください」と急かす
- 成功報酬だけと言いながら、調査費・実費・経費という名目で先に取る
- 弁護士名や事務所名を出さない、出しても検索して出てこない
- 「弁護士と提携している」と言うが、その弁護士と直接話せない
- LINEでのやり取りしかできない、書面を出さない
- 前払いの方法が現金手渡し、暗号資産、ギフト券

## 判断に迷ったときの最短ルート

**契約する前に、消費者ホットライン188か法テラスに「こういう業者から連絡が来たがどう思うか」と聞いてください。これは無料です。**

ここに一本電話を入れるだけで、二次被害はかなり防げます。相談員は同種の相談を毎日受けているので、業者名を言えば「その手口は聞いています」と即答されることも多い。

そして、**いま金銭的に追い詰められている状態で判断を急がないこと。** 焦っている人間の判断は、詐欺師にとっていちばん狙いやすい的です。一度やられた直後はその状態にある。

「今すぐ動け」というのは初動の話であって、業者への支払いは真逆です。**凍結依頼は即日、業者との契約は最低3日置く。** ここを分けてください。

## すでに二次被害に遭ってしまった場合

払ってしまった着手金についても、取り戻せる可能性があります。

- 契約から8日以内なら、訪問販売・電話勧誘販売に該当すればクーリング・オフ
- 消費者契約法の取消（不実告知・断定的判断の提供）
- 非弁行為が明らかなら、契約自体が公序良俗違反で無効になり得る（弁護士法72条違反の契約の効力を否定した裁判例があります）
- 特定商取引法の書面不備があれば、クーリング・オフ期間が進行していないという主張が可能

**消費生活センター（188）に相談してください。** ここは業者との斡旋（あっせん）に入ってくれます。無料です。

「相談しましょう」ではなく、**どこに何を相談すると何が起きるのか**を全部並べます。窓口によってできることが全然違うので、間違えると時間を失います。

> 電話番号・受付時間・料金は改定されることがあります。実行前に公式サイトで確認してください。

## 7-2. 公的機関（原則無料）

### 警察｜110番

**使うとき：** 被害の直後、犯人と接触中、身の危険がある、現金を渡す約束をしてしまった直後

**できること：** 緊急臨場、現行犯対応、口座凍結の情報を金融機関へ流す

**できないこと：** 民事の取り立て、金の回収そのもの

**ポイント：** 受け子との待ち合わせが設定されている場合、110番して警察に張ってもらうと現行犯逮捕につながります。この場合は自分だけで判断せず、必ず警察の指示に従ってください。

### 警察｜警察相談専用電話 #9110

**使うとき：** 緊急ではないが警察に相談したい、これが詐欺かどうか判断がつかない、どうすべきか分からない

**受付：** 平日8:30〜17:15（各都道府県で異なる。時間外は音声案内または当直へ）

**費用：** 無料（通話料は自己負担）

**できること：** 相談内容に応じて担当部署の案内、被害届の出し方の案内、防犯指導

**できないこと：** その場での捜査開始

**ポイント：** 家族の様子がおかしい（高額な振込を繰り返している等）といった段階でも相談できます。予防の窓口として非常に有効です。

---

### 警察｜被害届・告訴（最寄りの警察署）

**使うとき：** 詐欺の被害が確定した

**持っていくもの：** 身分証、印鑑、時系列メモ、証拠一式（プリントアウト）、振込明細、通帳

**できること：** 被害届の受理、捜査の端緒。受理番号が出れば金融機関やカード会社との交渉が速くなる

**できないこと：** 回収の保証、捜査状況の逐一の開示

**受理してもらえない場合の対処：**

「民事不介入なので」と言われるケースがあります。これは詐欺（刑事）と債務不履行（民事）の線引きの問題です。

通るように書き直すポイントは、**「最初から返す気がなかった」ことを示す事実**を並べることです。

- 説明された事業や運用の実体がなかった
- 集めた金が説明された用途に使われていない
- 同じ手口で複数の被害者がいる
- 最初から偽名・偽の住所を使っていた
- 元本保証など、実現不可能な条件を提示していた
- 返済期限が来た途端に連絡を絶った

これらを時系列メモに書き込んでから、もう一度行ってください。弁護士に告訴状を作ってもらうと通り方が変わります。

### 消費者ホットライン｜188（いやや）

**使うとき：** 契約トラブル全般、業者が怪しいかどうかの判断、解約したい、クーリング・オフしたい、二次被害の業者から連絡が来た

**受付：** 局番なしの188にかけると、最寄りの消費生活センターにつながる（各センターの受付時間による。平日日中が中心、土日は国民生活センターが対応する日もある）

**費用：** 無料（通話料は自己負担）

**できること：**
- 手口が既知のものかどうかの判断
- クーリング・オフや取消しが使えるかの助言
- **事業者との斡旋（あっせん）**。これが大きい。相談員が業者と直接交渉してくれるケースがあります
- 書面の書き方の指導
- 他の相談機関への引き継ぎ

**できないこと：** 相手が完全に匿名の詐欺グループの場合の追跡、訴訟の代理

**ポイント：** **この記事の中でいちばん使ってほしい窓口です。** 無料で、専門の相談員がいて、業者への斡旋までやってくれる。情報商材、副業、サブスク、点検商法、二次被害の業者。この系統は全部ここが強い。

「詐欺だから警察」と思って消費生活センターを飛ばす人が多いのですが、契約が絡む案件はここのほうが解決が速いことがよくあります。

**できること：** 家計改善支援、住居確保給付金、就労支援

**ポイント：** 被害額が大きくて生活が破綻しかけている場合、ここに行くのが早い。市区町村の福祉課で聞けます。

---

### こころの健康相談統一ダイヤル／精神保健福祉センター

**対象：** 精神的に追い詰められている場合

**ポイント：** 詐欺被害の後、自責と羞恥で誰にも言えず孤立するケースが非常に多い。金の話をしなくてもいいので、状態が悪いと感じたら使ってください。

---

### いのちの電話・よりそいホットライン

**ポイント：** 深夜・休日でもつながる窓口があります。追い詰められているなら、遠慮せずかけてください。

## 7-6. 相談するときの伝え方（3分で伝える型）

どの窓口でも、この順で話すと最短で本題に入れます。

1. **「詐欺の被害に遭いました」**（最初に結論）
2. **「〇月〇日に、〇〇円を、銀行振込で払いました」**（日付・金額・手段）
3. **「相手は〇〇と名乗る人物で、〇〇（SNS名）で知り合いました」**（相手の属性）
4. **「〇〇という名目でした」**（手口）
5. **「今日、振込先の銀行に凍結を依頼して、警察に被害届を出しました」**（済んでいる対応）
6. **「今日は、〇〇について伺いたいです」**（聞きたいこと）

経緯から時系列で話すと10分かかります。結論から入ってください。

## 7-7. 相談機関の使う順番

案件のタイプで変わります。

**タイプA：相手が分かっている（知人・業者）**

銀行凍結 → 警察（被害届）→ **弁護士**（本人交渉・訴訟）→ 必要なら法テラス

**タイプB：契約が絡む（情報商材・副業・サブスク・訪問販売）**

**消費生活センター（188）** → クレジット会社 → 必要なら弁護士

**タイプC：匿名の詐欺グループ（SNS投資・ロマンス・特殊詐欺）**

銀行凍結 → 警察（サイバー犯罪相談窓口含む）→ 188で情報提供 → 弁護士（回収可能性を診断してもらう）

**タイプD：登録業者とのトラブル**

業界団体のADR（FINMAC、そんぽADRなど）→ 金融庁 → 弁護士

**タイプE：借金を背負わされた**

法テラス → 日本クレジットカウンセリング協会 → 自治体の生活困窮者支援

# 第8章｜期限一覧：この日を過ぎると権利が消える

権利には期限があります。ここを知らずに放置して、法的に何もできなくなるケースがあります。

## 8-1. 時間軸で見る全体像

| 経過時間 | やること | 逃すと |
|---|---|---|
| 0〜1時間 | 追加送金停止、振込先銀行へ凍結依頼 | 残高が抜かれて分配ゼロ |
| 1〜6時間 | 各事業者へ連絡、証拠保全 | ページ・アカウントが消える |
| 当日中 | 110番・被害届、相手が分かるなら本人接触 | 相手が逃走準備に入る |
| 24〜72時間 | 内容証明の準備、消費生活センターへ相談 | クーリング・オフ期間が進む |
| 8日以内 | 訪問販売・電話勧誘販売のクーリング・オフ | 解除権が消える |
| 20日以内 | 連鎖販売取引・業務提供誘引販売取引のクーリング・オフ | 解除権が消える |
| 60日以内 | カードの不正利用の届出（多くの規約） | 盗難保険の補償対象外 |
| 120日程度 | チャージバックの申請 | 決済取消ができなくなる |
| 1年以内 | 消費者契約法・特商法の取消権（追認できる時から） | 取消権が消える |
| 3年以内 | 不法行為に基づく損害賠償請求（知った時から） | 時効 |
| 5年以内 | 不当利得返還請求、貸金返還請求、詐欺取消権 | 時効 |
| 7年以内 | 詐欺罪の公訴時効 | 刑事訴追ができない |
| 20年 | 不法行為の除斥的な上限 | 完全に消える |

## 8-2. クーリング・オフ期間の一覧

特定商取引法に基づく制度です。**通信販売にはクーリング・オフがありません**（返品特約に従う）。ここは間違えやすい。

| 取引類型 | 期間 | 主な例 |
|---|---|---|
| 訪問販売 | **8日** | 自宅への訪問、キャッチセールス、アポイントメントセールス |
| 電話勧誘販売 | **8日** | 電話で勧誘されて契約 |
| 特定継続的役務提供 | **8日** | エステ、美容医療、語学教室、家庭教師、学習塾、パソコン教室、結婚相手紹介 |
| 訪問購入 | **8日** | 押し買い（貴金属の買い取り訪問など） |
| 連鎖販売取引 | **20日** | マルチ商法、ネットワークビジネス |
| 業務提供誘引販売取引 | **20日** | 内職商法、モニター商法、「稼げる副業」系 |
| 通信販売 | **なし** | ネット通販（返品特約による。特約がなければ8日以内返品可・送料は購入者負担） |

**起算日は「法定書面を受け取った日」です。** 契約日ではありません。

ここが重要で、**業者が法律で定められた書面を渡していない、あるいは記載事項が欠けている場合、クーリング・オフ期間は進行を開始しません。** つまり何か月経っていても解除できる可能性がある。

情報商材や高額塾は書面不備が非常に多いので、期間を過ぎていても諦めずに188に相談してください。

なお2022年6月から、**メールなど電磁的記録によるクーリング・オフも可能**になりました。書面で送る場合は特定記録郵便または簡易書留で。

### 特定継続的役務提供の要件

これに該当すると8日のクーリング・オフに加えて、**中途解約権**（期間途中でも解約できる）が発生します。要件は業種で異なります。

| 業種 | 期間要件 | 金額要件 |
|---|---|---|
| エステティック | 1か月超 | 5万円超 |
| 美容医療 | 1か月超 | 5万円超 |
| 語学教室 | 2か月超 | 5万円超 |
| 家庭教師 | 2か月超 | 5万円超 |
| 学習塾 | 2か月超 | 5万円超 |
| パソコン教室 | 2か月超 | 5万円超 |
| 結婚相手紹介サービス | 2か月超 | 5万円超 |

## 8-3. 取消権の期限

| 根拠 | 期間 | 内容 |
|---|---|---|
| 民法96条（詐欺・強迫による取消） | 追認できる時から**5年**、行為の時から**20年** | 騙されて契約した |
| 消費者契約法4条 | 追認できる時から**1年**、契約時から**5年** | 不実告知、断定的判断の提供、不利益事実の不告知、不退去、退去妨害、過量契約、不安をあおる告知、デート商法など |
| 特定商取引法9条の3ほか | 追認できる時から**1年**、契約時から**5年** | 訪問販売等での不実告知・故意の事実不告知 |

**消費者契約法の取消権は1年です。** 民法の詐欺取消（5年）より短いので注意してください。「気づいた時から1年」なので、思っているより早く来ます。

消費者契約法で取消しやすい類型を挙げておきます。

- **不実告知：** 重要事項について事実と異なることを告げた（「元本保証です」「絶対に儲かります」）
- **断定的判断の提供：** 不確実な事項について確実だと告げた（「必ず値上がりします」）
- **不利益事実の不告知：** 利益になることだけ告げて、不利益な事実を故意に告げなかった
- **不退去：** 帰ってくれと言ったのに帰らない
- **退去妨害：** 帰りたいと言ったのに帰らせない
- **過量契約：** 通常の分量を著しく超える契約をさせた
- **不安をあおる告知：** 社会生活上の経験不足に乗じて、進学・就職・容姿などの不安をあおった
- **恋愛感情の不当利用（デート商法）**

## 8-4. 時効の一覧

| 請求の種類 | 時効期間 |
|---|---|
| 不法行為に基づく損害賠償請求 | 損害と加害者を知った時から**3年**、行為の時から**20年** |
| 生命・身体の侵害による損害賠償 | 知った時から**5年**、行為の時から**20年** |
| 不当利得返還請求 | 権利行使できると知った時から**5年**、行使できる時から**10年** |
| 貸金返還請求（個人間） | 知った時から**5年**、行使できる時から**10年** |
| 契約に基づく債権一般 | 知った時から**5年**、行使できる時から**10年** |

**詐欺被害で使う主戦場は「不法行為の3年」です。** これは思っているより短い。相手を特定できて「詐欺だった」と分かった時点からカウントが始まります。

### 時効を止める・伸ばす方法

| 方法 | 効果 |
|---|---|
| 内容証明での催告 | **6か月**の完成猶予 |
| 訴訟提起 | 訴訟中は完成猶予、確定判決で更新（そこから10年） |
| 支払督促の申立て | 完成猶予 |
| 民事調停・ADRの申立て | 完成猶予 |
| 仮差押え・仮処分 | 完成猶予 |
| **債務の承認（相手が認める書面、一部弁済）** | **時効が更新（ゼロからやり直し）** |

第4章で「その場で一筆もらえ」と書いた理由がここです。債務承認は時効を完全にリセットします。

なお、**催告による6か月の猶予は繰り返し使えません。** 内容証明を何度送っても、猶予は最初の1回分だけです。6か月の間に訴訟を起こす必要がある。

# 第9章｜法的手段の全体設計

初動が終わったら、ここからは回収フェーズです。手段は複数あって、順番と組み合わせで結果が変わります。

## 9-1. 全体の流れ

```
相手の特定
  ↓
内容証明での催告 ────────→ 支払われれば終了
  ↓（無視された）
財産の保全（仮差押え）      ← ここを飛ばすと勝訴しても回収できない
  ↓
債務名義を取る
  （支払督促／少額訴訟／通常訴訟／和解／公正証書）
  ↓
強制執行
  （財産開示手続・第三者からの情報取得手続）
  ↓
回収
```

刑事告訴はこの流れと**並行**して進めます。刑事事件化すると示談の可能性が出るので、実務上のショートカットになることがある。

## 9-2. 内容証明郵便

### 何をするものか

「いつ、誰が、誰に、どんな内容の手紙を出したか」を郵便局が証明してくれる制度です。手紙の内容自体に法的な効力があるわけではありません。

### 効果は3つ

1. **時効の完成を6か月猶予できる**（催告）
2. **相手にプレッシャーがかかる**。無視されることも多いですが、この段階で払う相手も一定数います
3. **「請求した」という事実が記録に残る**。後の訴訟で使えます

### 書き方

自分で書けます。ひな形は巻末に載せました。

書式のルール。

- 1行20字以内、1枚26行以内（縦書きの場合。横書きは別のパターンあり）
- 同じものを3通用意（相手用・郵便局保管用・自分用）
- 差出人・受取人の住所氏名を記載
- 図表や記号は使えない

e内容証明（電子内容証明）を使うと、24時間オンラインで出せて、字数制限もWordのテンプレートに従う形になります。こちらのほうが簡単です。

**必ず配達証明をつけてください。** 相手が受け取った日付が証明されます。

### 弁護士名義で出すかどうか

自分の名義でも法的効果は同じです。ただし、弁護士名義で届くと相手の受け止め方が変わります。「本気だ」と伝わる。

弁護士に内容証明の作成だけを頼む場合、相場は3〜5万円程度です。この段階だけスポットで頼むという使い方もあります。

## 9-3. 財産の保全（仮差押え）

### 順番として、実は訴訟より先に検討すべきもの

裁判をやっている数か月から1年のあいだに、相手は財産を隠します。勝訴判決を取ったときには口座が空だった。これがいちばんよくある結末です。

だから、相手に不動産や預金があると分かっているなら、訴訟の前か同時に仮差押えをかけて動かせなくする。

### 対象になるもの

- 預貯金（銀行・支店を特定する必要がある）
- 不動産
- 給与債権
- 売掛金
- 自動車

### ハードル：担保金

**申立てには担保金を法務局に供託する必要があります。** 相場は請求額の1〜3割程度。

300万円の請求なら、30万〜90万円を先に用意することになる。被害に遭って手元に金がない状態でこれを出すのはきつい。ここが最大の障壁です。

ただし、事件が終われば担保金は返ってきます（担保取消しの手続きが必要）。「消える金」ではなく「一時的に預ける金」です。

### 判断基準

- 相手の財産のありかが分かっている → やる価値が高い
- 相手が財産を処分しそうな兆候がある → 急ぐ
- 被害額が担保金を大きく上回る → 合理性がある
- 相手の財産が分からない → 空振りになるのでやらない

## 9-4. 債務名義を取る4つのルート

「債務名義」というのは、強制執行をするための資格を持った書類のことです。判決、和解調書、支払督促、公正証書などが該当します。

### ルートA：支払督促

**向く場合：** 相手が争ってこない見込み、書面上の債権が明確

**費用：** 訴訟の半額（印紙代）。100万円の請求で5,000円程度

**手続き：** 簡易裁判所に申立て → 裁判所が相手に支払督促を送達 → 相手が2週間以内に異議を出さなければ、仮執行宣言の申立てができる → さらに2週間異議がなければ確定判決と同一の効力

**注意：** 相手が異議を出すと通常訴訟に移行します。しかも**相手の住所地の裁判所**に移るので、遠方だと不利になる。争ってくる相手には向きません。

### ルートB：少額訴訟

**向く場合：** 60万円以下の金銭請求、証拠が明確

**費用：** 印紙代（60万円の請求で6,000円程度）＋郵券

**手続き：** 簡易裁判所に訴え → **原則1回の期日で審理を終えて判決**

**制限：**
- 60万円以下の金銭支払請求のみ
- 同一の簡易裁判所で年10回まで
- 相手が通常訴訟への移行を申し立てられる
- 判決に対して控訴はできない（異議申立てのみ）

**ポイント：** 1回で終わるのが最大の利点。証拠を全部その日に持っていく必要があります。

### ルートC：通常訴訟

**向く場合：** 金額が大きい、争点がある、相手が争ってくる

**費用（印紙代の目安）：**

| 訴額 | 印紙代 |
|---|---|
| 100万円 | 10,000円 |
| 300万円 | 20,000円 |
| 500万円 | 30,000円 |
| 1,000万円 | 50,000円 |
| 3,000万円 | 110,000円 |

これに郵券（数千円）と、弁護士に頼むなら弁護士費用が乗ります。

**期間：** 半年〜1年半程度。争点が多いと2年を超えることもある

**ポイント：** 途中で和解になるケースが多いです。判決まで行くより早く終わり、相手も分割で払いやすくなる。回収を目的とするなら、和解は悪い選択ではありません。

### ルートD：民事調停

**向く場合：** 相手が話し合いに応じる、関係を完全に壊したくない

**費用：** 訴訟より安い

**手続き：** 簡易裁判所で調停委員を交えて話し合い。成立すれば調停調書が作られ、これは確定判決と同一の効力を持つ

**注意：** 相手が出頭しなければ不成立で終わります。逃げている相手には使えません。

## 9-5. 刑事告訴

### 被害届との違い

| | 被害届 | 告訴 |
|---|---|---|
| 内容 | 被害の事実を申告する | 犯人の処罰を求める意思表示 |
| 警察の義務 | 受理する | 受理したら捜査して検察に送致する義務がある |
| ハードル | 低い | 高い（受理してもらいにくい） |
| 効果 | 捜査の端緒 | 捜査を促す力が強い |

**告訴のほうが強力です。** ただし受理してもらうハードルが高く、実務上は弁護士に告訴状を作ってもらうことが多い。

### 告訴状に書くこと

1. 告訴人（自分）の氏名・住所
2. 被告訴人（相手）の氏名・住所
3. 告訴の趣旨（「詐欺罪で処罰を求める」）
4. 告訴の事実（詳細な時系列。ここが本体）
5. 立証方法（証拠の一覧）
6. 添付書類

詐欺罪の構成要件（欺罔行為 → 錯誤 → 交付 → 財産の移転）に沿って事実を並べるのがコツです。**「最初から返す・履行する意思も能力もなかった」ことを示す事実**を厚く書く。

### 回収との関係

刑事は処罰のための手続きなので、直接には金が戻りません。ただし。

- 刑事事件になると、相手が**示談**を申し出てくることがある（示談すると量刑が軽くなるため）
- 検挙されれば相手の身元が確定するので、民事訴訟が可能になる
- 押収された財産から被害弁償が行われることがある
- 「犯罪被害財産等による被害回復給付金支給制度」に該当する場合がある（組織的詐欺など特定の類型）

**実務上、刑事事件化してから返ってくるパターンは少なくありません。** 特に相手が社会的地位のある人物や事業者の場合、前科を避けるために払ってきます。

## 9-6. 強制執行：勝訴と回収の距離

ここが最も誤解されている部分です。

**判決は「払え」と書いてある紙です。自動的に金は振り込まれません。**

相手の財産を自分で特定して、強制執行の申立てをして、初めて回収になります。相手に何もなければ、勝訴しても0円です。

### 財産を見つける手段

**財産開示手続（民事執行法196条〜）**

債務名義を持っていれば申し立てられます。相手を裁判所に呼び出して、財産の状況を陳述させる手続き。

2020年の改正で**罰則が強化**され、不出頭や虚偽陳述には6か月以下の拘禁刑または50万円以下の罰金が科されるようになりました。改正前は過料だけで実効性が乏しかったのですが、いまは刑事罰なので出頭率が上がっています。

**第三者からの情報取得手続（民事執行法204条〜）**

裁判所を通じて第三者から情報を取る手続きです。ここは対象債権によって使える範囲が違うので、正確に整理します。

| 取得する情報 | 提供元 | 使える債権 | 前提条件 |
|---|---|---|---|
| 預貯金の情報 | 金融機関 | **一般の債権でOK** | なし |
| 上場株式・国債等 | 証券会社等 | 一般の債権でOK | なし |
| 不動産の情報 | 法務局 | 一般の債権でOK | **財産開示手続の前置が必要** |
| 給与（勤務先）の情報 | 市町村・年金機構 | **養育費等と、生命身体侵害の損害賠償に限る** | 財産開示手続の前置が必要 |

**詐欺の金銭被害では、給与情報の取得は使えません。** ここは重要なので押さえておいてください。財産的損害だけの場合、勤務先を裁判所経由で調べることはできない。

だから、第4章で「勤務先を知っているか」を診断項目に入れているんです。自分で知っていれば給与の差押えができます。

### 差押えの制限

- 給与は原則として**手取りの4分の1まで**（手取りが44万円を超える場合は、33万円を超える部分は全額差押え可能）
- **現金は66万円まで差押禁止**
- 生活に必要な家財道具は差押禁止

### 費用対効果の判断

強制執行にも費用がかかります（予納金、執行官の手数料）。少額の債権で空振りの執行を繰り返すと、費用のほうが上回ります。

**財産のありかを掴んでいる相手なら回収の見込みは高い。掴んでいないなら、財産開示手続から始める。** 順番はこれです。

## 9-7. 手段の比較表

| 手段 | 費用 | 期間 | 相手が逃げていても使えるか | 向く場面 |
|---|---|---|---|---|
| 内容証明 | 数千円〜5万円 | 即日 | 住所が必要 | 最初の一手 |
| 仮差押え | 担保金（請求額の1〜3割） | 数週間 | 財産の特定が必要 | 財産があると分かっている |
| 支払督促 | 訴訟の半額 | 1〜2か月 | 住所が必要 | 争われない見込み |
| 少額訴訟 | 数千円 | 1〜2か月 | 住所が必要 | 60万円以下 |
| 通常訴訟 | 印紙代＋弁護士費用 | 半年〜1年半 | 住所が必要 | 金額が大きい |
| 民事調停 | 数千円 | 1〜3か月 | 出頭しないと不成立 | 話し合いの余地あり |
| 刑事告訴 | 弁護士に頼むと10〜30万円 | 数か月〜 | **住所不明でも出せる** | 相手が特定できない |
| ADR | 1万円程度〜 | 1〜3か月 | 出てこないと不成立 | 相手が登録業者 |

**相手の住所が分からない場合、民事の選択肢はほぼ全部使えません。** 刑事ルートか、弁護士会照会での特定が先になります。

# 第10章｜弁護士の使い方と費用の全部

## 10-1. いつ頼むべきか

すぐ頼むべきケース。

- 被害額が100万円を超える
- 相手が特定できていて、財産がありそう
- 相手が法人、または事業者
- 相手が弁護士を立ててきた
- 刑事告訴を出したい
- 相手の特定に弁護士会照会が必要

急がなくていいケース。

- 契約トラブル系（まず188のほうが速くて無料）
- 被害額が数万円（費用倒れになる）
- 相手が完全に匿名で、口座凍結以外に打つ手がない

## 10-2. 費用の相場

弁護士報酬は自由化されていますが、多くの事務所が旧日弁連報酬基準を参考にしています。目安として。

### 法律相談

30分5,500円程度。初回無料の事務所もあります。

### 着手金（結果に関わらず発生）

| 経済的利益 | 着手金の目安 |
|---|---|
| 300万円以下 | 8%（最低10万円程度） |
| 300万〜3,000万円 | 5% + 9万円 |
| 3,000万〜3億円 | 3% + 69万円 |

300万円の被害なら着手金24万円、1,000万円なら59万円が目安です。

### 報酬金（回収できたら発生）

| 経済的利益 | 報酬金の目安 |
|---|---|
| 300万円以下 | 16% |
| 300万〜3,000万円 | 10% + 18万円 |
| 3,000万〜3億円 | 6% + 138万円 |

**「回収できた額」に対してかかります。** 300万円請求して100万円しか回収できなければ、報酬金は100万円に対する16%です。

### その他

- 内容証明の作成のみ：3〜5万円
- 実費：印紙代、郵券、交通費、弁護士会照会の費用、記録の謄写代など
- 日当：出張1日で5〜10万円程度

### 完全成功報酬の事務所

着手金0円の事務所もあります。ただしその分、報酬金の率が高い（30〜40%など）ことが多い。回収の見込みが低い案件は受けてもらえません。

## 10-3. 費用を下げる4つのルート

**1. 法テラスの民事法律扶助**

資力要件を満たせば、弁護士費用を立て替えてもらえます（第7章参照）。月5,000〜10,000円の分割で返済。

**2. 弁護士費用特約**

**これを見落としている人が非常に多い。**

自動車保険や火災保険、クレジットカードの付帯保険に「弁護士費用特約」がついていることがあります。以前は交通事故限定が多かったのですが、**日常生活のトラブル全般（日常生活型）に使えるタイプが増えています。**

限度額は300万円程度が一般的。詐欺被害に使えるかどうかは約款次第ですが、**保険会社に確認する価値は絶対にあります。** 使っても等級は下がりません。

自分の保険、家族の保険（同居の親族が対象になることが多い）、両方確認してください。

**3. 自治体の無料法律相談**

市区町村が定期的に開催しています。1回30分程度、予約制。方針を決めるだけなら十分使えます。

**4. 弁護士会の法律相談センター**

30分5,500円程度。分野に強い弁護士を割り振ってくれます。

## 10-4. 面談で必ず聞く12の質問

弁護士に会ったら、これを聞いてください。答え方で相性と実力が分かります。

1. この案件の回収可能性は、率でいうとどのくらいですか
2. その判断の根拠は何ですか
3. 回収できなかった場合、私が負担する金額は総額いくらですか
4. 着手金・報酬金・実費・日当の内訳を書面でいただけますか
5. 想定される期間はどのくらいですか
6. 相手の特定はできそうですか。どの手段を使いますか
7. 仮差押えは検討する価値がありますか
8. 刑事告訴は出したほうがいいですか
9. 同種の案件を扱った経験はありますか
10. 私自身が今すぐやるべきことは何ですか
11. 連絡はどのくらいの頻度で来ますか。窓口は先生ご本人ですか
12. 途中で見込みがないと判断した場合、どうなりますか

**3番と12番の答え方が特に重要です。** ここを曖昧にする弁護士は避けたほうがいい。

## 10-5. 依頼すべきでないサイン

- 「必ず取り返せます」と言う（弁護士でもこれを言う人はいます。避けてください）
- 費用の説明が口頭だけ
- 委任契約書を交わさない
- 質問への回答が抽象的
- 事務員としか話せない
- 契約を急がせる

## 10-6. 依頼したあとの付き合い方

- 資料は整理して渡す（時系列メモがここで効きます）
- 相手から直接連絡が来たら、自分で対応せず弁護士に回す
- 新しい情報は都度共有する
- 進捗が3か月動かないなら確認する

## 10-7. 司法書士という選択肢

被害額が140万円以下なら、認定司法書士に依頼するほうが安いことがあります。

**できること：** 簡易裁判所の管轄（訴額140万円以下）での代理、書類作成（金額制限なし）

**できないこと：** 140万円を超える案件の代理、地方裁判所での代理、刑事告訴の代理

**確認すること：** 「認定司法書士ですか」と必ず聞いてください。認定を受けていないと代理交渉ができません。

# 第11章｜手口別・完全対応マニュアル

自分の案件に該当するものを引いてください。

## 11-1. 特殊詐欺（警察を騙る電話・オレオレ・還付金）

### 手口の構造

警察官、銀行員、市役所職員、金融庁職員などを名乗る電話から始まります。近年はビデオ通話で**偽の警察手帳や偽の逮捕状を見せてくる**手口が増えています。

典型的な流れ。

1. 「あなたの口座が犯罪に使われています」
2. 「捜査に協力してください。この件は他言しないでください」
3. 「あなたの資産が犯罪収益でないことを証明する必要があります」
4. 「一時的に指定の口座へ移してください」または「アプリで残高を確認させてください」

### 気づくポイント（家族に教える用）

- **警察も銀行も役所も、電話で金の話をしません**
- 現金の移動、口座の変更、ATMの操作を電話で指示することは絶対にない
- 「あなたの資産を保護するために別口座へ移す」という手続きはこの世に存在しない
- 「他言しないでください」は詐欺の合図
- 還付金をATMで受け取る手続きは存在しない

### 初動

**即、振込先金融機関へ凍結依頼と110番。**

この手口は口座から口座への即時移動が前提で組まれているので、**当日中に凍結できなければ回収はほぼ絶望的**です。翌日には残高が残っていません。

ATMで操作している最中に気づいたなら、その場で操作を中止して銀行員か警察を呼ぶ。

### 回収可能性

当日中の凍結が間に合えば分配の可能性あり。翌日以降はほぼゼロ。犯人グループが検挙されれば被害回復給付金の対象になることがあります。

### 使う窓口

振込先銀行 → 110番 → 警察署（被害届）→ #9110（家族の相談）

## 11-2. SNS型投資詐欺

### 手口の構造

InstagramやFacebook、YouTubeの広告から始まります。著名人の写真や名前を無断使用したものが多い。

1. 投資の情報を無料で配信するという広告
2. LINEの公式アカウントへ誘導
3. グループに入れられる（他の参加者は全員サクラ）
4. 「先生」「アシスタント」という役割の人物が登場
5. 少額から始めさせ、専用アプリ上で利益が出ているように見せる
6. 少額なら実際に出金できる（信用させるため）
7. 大きく入金させる
8. 出金しようとすると「税金」「手数料」「保証金」を要求
9. 払っても出金できず、連絡が途絶える

### 気づくポイント

- 金融庁に登録されていない業者（**金融庁のサイトで検索してください。1分で終わります**）
- 専用アプリで運用状況を見せる（実在の証券口座ではない）
- 元本保証、確実に儲かるという表現
- 出金に手数料や税金の前払いを求める
- LINEグループの参加者が全員うまくいっている

### 初動

**最優先は「追加送金を止めること」です。**

出金のために先に金を払えというのは、まず間違いなく詐欺です。本当に利益が出ているなら利益から引かれる。ここで止められれば被害は確定分で済みます。

「もう一度だけ送金すれば全部戻る」は、被害額を膨らませるための言葉です。

そのうえで、振込先の凍結依頼、警察のサイバー犯罪相談窓口、金融庁への情報提供。

### 回収可能性

低い。ただし振込先が国内の口座であれば、凍結が間に合えば分配の可能性があります。近年は組織的な摘発も進んでいるので、被害届は必ず出してください。

### 使う窓口

振込先銀行 → 警察（サイバー犯罪相談窓口）→ 金融庁 → 188

## 11-3. SNS型ロマンス詐欺・国際ロマンス詐欺

### 手口の構造

マッチングアプリやSNSで知り合い、数週間から数か月かけて関係を作ってから金の話を出します。

典型的な人物設定：海外在住の医師、軍人、エンジニア、実業家。写真は他人のものを流用。

金を出させる名目：投資、税関の手数料、荷物の受け取り費用、医療費、渡航費、暗号資産の運用。

### 気づくポイント

- 会えない理由が常にある
- ビデオ通話を避ける、または短時間・不鮮明
- 早い段階で「愛している」と言う
- 金の話が出てくる
- 送金先が本人名義ではない

### 初動

**追加送金の停止と、送金先の凍結依頼。**

暗号資産で送っている場合は取引所へ。海外送金なら送金した金融機関へ組戻しの依頼（受取人が引き出す前なら止まる可能性があります）。

### 回収可能性

かなり低い。海外の口座や暗号資産に流れているケースが多い。

ただし**近年は国内の受け皿口座を使うケースも増えていて**、その場合は凍結が効きます。

### 使う窓口

警察（サイバー犯罪相談窓口）→ 送金先銀行・取引所 → 188

### 注意

この手口は**二次被害の標的にされやすい**類型です。「国際ロマンス詐欺の返金に強い」という業者が大量に存在します。第6章を読んでから判断してください。

## 11-4. 副業詐欺・タスク詐欺

### 手口の構造

「スマホで簡単に稼げる」から入って、段階的に費用を積み上げる型。

1. 簡単なタスク（動画を見る、いいねを押す）で少額の報酬が実際に振り込まれる
2. 「もっと稼げるコース」に誘導
3. 登録料、サポート料、ランクアップ費用を請求
4. 「あなたの操作ミスで凍結された。解除には追加費用が必要」と言われる
5. 消費者金融やカードのキャッシングで借りさせられる

### 気づくポイント

- 最初に少額が実際に振り込まれる（信用させる仕掛け）
- 稼ぐために先に払う構造
- 「操作ミス」「システムエラー」で追加費用が発生する
- 借入を勧めてくる

### 初動

**追加送金の停止。そして借入があるならその契約書も全部揃える。**

この類型は**業務提供誘引販売取引**に該当する可能性があり、その場合クーリング・オフ期間が**20日**になります。さらに書面不備があれば期間が進行していない可能性がある。

### 回収可能性

**中程度。** 契約が絡むので、消費生活センターの斡旋やクーリング・オフで解決するケースがあります。

### 使う窓口

**188（最優先）** → クレジット会社 → 法テラス（借金がある場合）

### 注意

借金までさせられている場合、返済に追われて相談が遅れるという二重の罠になります。**借入の有無は隠さず全部言ってください。** 隠すと打てる手が減ります。

## 11-5. 情報商材・高額塾・オンラインサロン

### 判断が難しい領域

「効果がなかった」というだけでは詐欺になりません。ここは冷静に整理する必要があります。

争える要素があるのは、**契約前の説明に虚偽があった場合**です。

- 「絶対に稼げる」「返金保証あり」と言われたが実際は違った
- 実績のスクリーンショットが捏造だった
- 講師の経歴が虚偽だった
- 「今だけ」と言われたが常時販売していた
- サポートを提供すると言ったが実体がなかった

### 初動

**セールスページ、セミナー動画、LINEのやり取り、決済画面を全部保存。**

サイトは消えます。特に返金要求が増えると即座に消える。

### 使える制度

- **特定商取引法の書面交付義務**。法定書面が交付されていない、または記載不備があれば、クーリング・オフ期間が進行していない可能性がある
- **消費者契約法の取消**（不実告知・断定的判断の提供）
- **連鎖販売取引に該当する場合は20日のクーリング・オフ**（紹介料が発生する仕組みなら該当の可能性）
- **特定継続的役務提供に該当する場合は中途解約権**
- **クレジット決済ならチャージバックまたは支払停止の抗弁**

### 回収可能性

**中〜高。** 事業者が実在していて、契約書面に不備があるケースが多いので、188の斡旋で解決することがよくあります。

### 使う窓口

**188（最優先）** → クレジット会社 → 弁護士（金額が大きい場合）

## 11-6. 未公開株・社債・ファンド型

### 手口の構造

「上場が決まっている未公開株」「高利回りの社債」を電話や訪問で勧誘。パンフレットが立派なのが特徴。

**劇場型**という手法がよく使われます。複数の業者が別々の役を演じる。

1. A社から「未公開株のパンフレット」が届く
2. B社から電話で「A社の株を高く買い取りたい。持っていないか」
3. 「では買っておくと儲かる」と思わせてA社から購入させる
4. B社は消える

### 気づくポイント

- **金融庁に登録されていない業者が金融商品を勧誘している**（無登録営業は金商法違反）
- 「あなただけ」「特別枠」
- 元本保証・高利回りの明示
- 買い取りを申し出る第三者が現れる

### 初動

**金融庁の登録業者一覧で検索。載っていなければその時点で違法営業です。**

金融庁は「無登録で金融商品取引業を行う者の名称等について」というリストも公表しています。

### 回収可能性

低〜中。業者に実体があれば取れる可能性があります。

### 使う窓口

金融庁 → 警察 → 弁護士 → 188

## 11-7. サポート詐欺（偽警告）

### 手口の構造

Webサイト閲覧中に「ウイルスに感染しました」という警告画面と警告音が出る。表示された番号に電話すると、遠隔操作ソフトを入れさせられ、サポート料としてコンビニでギフト券を買わされる。

### 気づくポイント

- 警告画面に電話番号が書いてある（本物のセキュリティソフトは電話をかけさせません）
- ブラウザが閉じられない（全画面表示にされているだけです。Escキーやタスクマネージャーで閉じられます）
- 支払方法がギフト券やコンビニ払い

### 初動

**ギフト券のコードを伝えていないなら、発行元に連絡して止める。レシートは絶対に捨てない。**

遠隔操作ソフトを入れてしまった場合は、ソフトのアンインストール、ネットバンキングのパスワード変更、可能ならPCの初期化。

### 回収可能性

コード未使用なら高い。使用後は低い。

### 使う窓口

ギフト券の発行元 → 警察（サイバー犯罪相談窓口）→ 188

## 11-8. フィッシング（偽サイトでの情報詐取）

### 初動

**カード会社・銀行に即連絡してカードと口座を止める。パスワードを全部変更する。**

同じパスワードを使い回している他のサービスも全部変えてください。

### 使う窓口

カード会社・銀行 → フィッシング対策協議会への情報提供 → 警察（サイバー犯罪相談窓口）

## 11-9. 知人・友人・親族からの投資話

### 特徴

**この記事の中でいちばん回収可能性が高い類型です。** 相手が実在していて、住所も勤務先も分かっている。

そして、いちばん動けなくなる類型でもあります。「相手を信じたい」「まだ返ってくるかも」「関係を壊したくない」。

### 初動

**第4章を実行してください。今日中に会いに行く。**

### 動くべきタイミングの判断基準

ひとつだけ。**返済期限を過ぎて連絡の頻度が落ちたら、もう終わっています。** そこから待っても状況は良くなりません。

その1か月で、他の被害者に原資が渡ります。

### 回収可能性

高い。ただし動くのが遅れるほど下がります。

### 使う窓口

本人 → 弁護士 → 警察（詐欺の要件を満たす場合）

## 11-10. 事業者間の取引・前払い金の未履行

### 特徴

リフォーム工事、システム開発、商品の仕入れ、事業譲渡。前払いしたが履行されないケース。

### 詐欺と債務不履行の線引き

ここが争点になります。「最初から履行する意思も能力もなかった」なら詐欺、「やろうとしたができなかった」なら債務不履行。

詐欺を主張するために集める事実。

- 受け取った金が説明された用途に使われていない
- 同時期に複数の相手から同じように前払いを受けている
- 履行に必要な資格・許可を持っていなかった
- 会社の実体がなかった

### 初動

内容証明で履行の催告 → 期限を切って解除 → 返還請求。並行して財産の保全を検討。

### 回収可能性

相手が事業を続けているなら高い。倒産・逃走されると急落します。だから速度が効きます。

### 使う窓口

弁護士 → 警察（詐欺の要件を満たす場合）

事業者間取引には消費者契約法や特定商取引法は使えません。ここは民法の勝負になります。

## 11-11. 訪問販売・点検商法・リフォーム詐欺

### 手口の構造

「近くで工事をしているので無料で点検します」「屋根が壊れています」と訪問し、不安をあおって高額な契約をさせる。

### 初動

**クーリング・オフ（8日）。** 工事が終わっていても使えます。

高齢者が被害に遭いやすい類型です。家族が気づいたら、まず契約書面の日付を確認してください。

### 回収可能性

**高い。** クーリング・オフが使えるので、期間内なら全額戻ります。期間を過ぎていても、書面不備や消費者契約法の取消で争える。

### 使う窓口

**188（最優先）**

## 11-12. 訪問購入（押し買い）

「不要な服を買い取ります」と訪問して、貴金属を安値で持ち去る手口。

**クーリング・オフは8日。しかもこの期間中は、業者は物を第三者に引き渡してはいけない義務があります。** すぐ188へ。

## 11-13. マルチ商法・ネットワークビジネス

**連鎖販売取引に該当すれば、クーリング・オフは20日。**

さらに、**中途解約と返品の制度**があります（入会後1年以内、引渡しから90日以内の未使用商品など、要件あり）。

人間関係が絡むので相談しにくい類型ですが、188は慣れています。

## 11-14. 給付金・補助金詐欺

「給付金の申請を代行します」と言って手数料を取る、あるいは不正受給に加担させられるケース。

**不正受給に加担すると、自分が刑事責任を問われます。** 「代わりに申請してあげる」という話に乗ってしまった場合、被害者ではなく加害者になる可能性がある。この場合は**すぐに弁護士へ**。自主的に返還すれば処分が軽くなる可能性があります。

## 11-15. 闇バイト（加害者側に回ってしまった場合）

「高額報酬」の求人に応募して、受け子や出し子をやらされてしまったケース。

これは被害ではなく犯罪への加担です。ただし、**やめたくてもやめさせてもらえない**（身分証を握られて脅される）という状況が典型的に起きます。

**すぐに110番、または弁護士へ。** 身分証を渡していても、警察に相談することで保護されます。自首すれば処分が軽くなる可能性があります。逃げ続けるほど状況は悪化します。

# 第12章｜なぜ引っかかったのか（心理の解剖）

回収の話が終わったので、ここからは再発防止です。

「自分は判断力がある」と思っている人ほど狙われます。理由は、詐欺が判断力を試す仕掛けではなく、**判断させない仕掛け**だからです。

## 12-1. 詐欺のスクリプトは6段階でできている

どの手口も、この構造を持っています。

**段階1：接触**
広告、DM、電話、知人の紹介。ここでは何も売らない。

**段階2：関係の構築**
情報を無料で与える。親切にする。時間をかける。ここで「この人は自分に利益をくれる人だ」という前提が作られる。

**段階3：小さなコミットメント**
少額の投資、無料の登録、簡単なタスク。**そして実際に小さな成功体験を与える。** ここが決定的です。少額で出金できると、システム全体が本物だと錯覚する。

**段階4：本命の提示**
「今なら」「あなただけ」「あと〇名」。時間的な圧力をかける。考える時間を与えない。

**段階5：一貫性の利用**
一度払った人は、判断が正しかったことを証明したくなる。だから追加投資を断りにくくなる。これは**サンクコストの心理**です。「ここでやめたら今までの分が無駄になる」。

**段階6：出口の封鎖**
出金しようとすると条件が追加される。「税金」「手数料」「保証金」。ここで初めて被害が確定する。

**段階3で止められる人はいません。** 実際に少額が戻ってくるからです。止められるのは段階4か5です。「時間的な圧力がかかったら、いったん退く」。これだけを覚えておいてください。

## 12-2. 使われる心理原理

| 原理 | 使われ方 |
|---|---|
| **返報性** | 先に無料で価値を与える。人は借りを返したくなる |
| **一貫性** | 小さなYESを積み重ねて、大きなYESを引き出す |
| **社会的証明** | サクラだらけのグループチャット。「みんな儲かっている」 |
| **権威** | 偽の資格、著名人の写真、偽の警察手帳、立派なオフィス |
| **希少性** | 「今だけ」「あと3名」「特別枠」 |
| **好意** | 時間をかけて関係を作る。ロマンス詐欺はこれが主軸 |
| **サンクコスト** | 「ここでやめたら今までの分が無駄」 |
| **秘密の共有** | 「他言しないでください」。相談させないための仕掛け |

「他言しないでください」は、**第三者の判断を遮断するための装置**です。詐欺で最も効くカウンターは「誰かに話すこと」なので、そこを先に封じてくる。

だから逆に言えば、**「他言するな」と言われた時点で詐欺を疑ってください。** 正当な取引で他言を禁じる理由はほとんどありません。

## 12-3. 判断力が落ちる条件

以下の状態にあるとき、人は詐欺に対して脆くなります。

- 金銭的に追い詰められている
- 孤独である（相談相手がいない）
- 大きな変化の直後（退職、離婚、死別、引っ越し、病気）
- 睡眠不足
- 高齢で、日中ひとりでいる時間が長い
- 「自分は騙されない」と思っている
- 一度詐欺に遭った直後

最後の2つが重要です。**「自分は騙されない」という確信は、検証を止めるので脆さになります。** そして被害直後は、取り返したいという焦りで判断が歪む。

## 12-4. 「なぜ気づけなかったのか」に対する答え

被害に遭った人が最も苦しむのがこの問いです。

答えははっきりしていて、**気づけない設計だったから**です。

詐欺のスクリプトは、何千人にも試して、引っかかる確率が高い順に最適化されています。個人の注意力と、最適化されたスクリプトの勝負ではない。営業のプロが売り込みに来ているのと同じ構造です。

被害に遭ったことは判断力の問題ではありません。手口が精緻になっているだけです。

ここを自責で処理すると、誰にも言えなくなり、孤立して、二次被害に遭います。**この因果関係を切ることが、再発防止の第一歩です。**

# 第13章｜取り返せなかったときの生活再建

現実として、戻らない場合のほうが多い。そのときにやることも書いておきます。

## 13-1. 損切りのタイミングを決める

回収に費やす時間と精神力にもコストがあります。弁護士と話して見込みがゼロなら、そこで区切る判断も必要です。

**取り返そうとして二次被害に遭う人は、この区切りをつけられなかった人が多い。**

区切りの基準の例。

- 弁護士2人に相談して、どちらも回収可能性が低いと言った
- 相手が特定できず、特定手段も尽きた
- 相手に財産がないことが財産開示手続で確定した
- 追加でかかる費用が、期待できる回収額を上回る

このどれかに当たったら、被害届は出したまま、日常の再建に切り替えてください。**捜査は続きます。** 数年後に検挙されて連絡が来ることも実際にあります。

## 13-2. 税務の扱い（勘違いが多い部分）

**雑損控除は詐欺による被害には使えません。**

所得税法上の雑損控除の対象は、**災害・盗難・横領**に限られています。詐欺と恐喝による損失は対象外です。ネット上に「雑損控除で取り戻せる」という不正確な情報が出回っているので、注意してください。

例外的に検討できるケース。

- **事業に関連する損失なら、事業所得の必要経費（貸倒損失）として計上できる可能性があります。** 事業として行っていた取引での焦げ付きなら、貸倒れの要件を満たせば損金になる
- 業務上横領なら雑損控除の対象になり得る

いずれも判断が難しいので、**税理士に確認してください。**

## 13-3. 借金がある場合

被害で借金を背負った場合、返済に追われて他のことができなくなります。ここは早めに手を打つ。

- **法テラス**で債務整理の相談
- **日本クレジットカウンセリング協会**（無料）
- 任意整理・個人再生・自己破産の検討

「詐欺で借りた金だから自分が悪い」と考える必要はありません。制度は使うためにあります。

## 13-4. 名簿対策

被害後は勧誘の電話とDMが増えます。

- 知らない番号は出ない
- 出てしまったら「今後一切連絡しないでください」と一度だけ明確に伝えて切る（**この一言には特定商取引法上の意味があります。**再勧誘は禁止されています）
- 迷惑電話ブロックのサービスを設定する
- 固定電話は留守番電話を常時オンにする（特殊詐欺の対策として最も効果があります）
- 「名簿を削除します」という業者には絶対に金を払わない（これ自体が詐欺です）

## 13-5. 口座・カード・パスワードの整理

- 相手に口座番号やカード番号を渡しているなら、番号変更を検討
- パスワードを使い回しているなら全部変える
- ネットバンキングの二段階認証を設定する
- 使っていない口座を解約する（口座を売れと言われるリスクを減らす）

**絶対にやってはいけないこと：口座やカードを他人に譲渡・貸与すること。** 「口座を貸してくれれば損失を補填する」という誘いが来ることがありますが、これは犯罪収益移転防止法違反で、**自分が犯罪者になります。**

## 13-6. メンタルと人間関係

詐欺被害の後に起きること。

- 自責と羞恥で誰にも言えない
- 家族に言えないまま、ひとりで挽回しようとする
- その状態で次の投資話に乗ってしまう
- 判断力が落ちているので、また引っかかる

この流れが本当に多い。

**誰かに言ってください。** 言った時点で二次被害の確率はかなり下がります。

言う相手は、家族でも友人でも、相談機関の相談員でも構いません。第7章に挙げた窓口は、話を聞くことに慣れています。判断できない状態のときに、外部の判断を入れるのが目的です。

精神的に厳しいなら、こころの健康相談統一ダイヤルや自治体の精神保健福祉センターを使ってください。金の話をしなくても構いません。

## 13-7. 家族への説明の仕方

言えない理由の大半は「責められるのが怖い」です。

伝え方のコツ。

1. **結論から言う。** 「詐欺に遭って、〇〇円を失った」
2. **すでに取った対応を並べる。** 「銀行に凍結を依頼して、警察に被害届を出した」
3. **今後の方針を言う。** 「弁護士に相談して、回収の見込みを判断してもらう」
4. **経緯の説明は後回しにする。** 「どうして気づかなかったのか」の話を先にすると、そこで議論が止まる

対応を先に示すと、話が「責任追及」ではなく「対策」に向かいます。

# 第14章｜二度と遭わないための防御設計

意志の力ではなく、仕組みで防ぎます。

## 14-1. 口座の構造を変える

- **生活口座と貯蓄口座を分ける。** 生活口座には必要最小限しか置かない
- 貯蓄口座はネットバンキングを使わない、またはキャッシュカードを持ち歩かない
- 大口の資金は定期預金にする（引き出しに手間がかかる状態にする）
- ATMの1日の引出限度額を下げる（銀行の窓口で設定できます）
- 高齢の家族には、ATMの振込限度額をゼロに設定してもらう

**限度額の設定は、特殊詐欺への対策として最も効果があります。** 5分で終わるので、今日やってください。

## 14-2. 連絡先の運用ルール

- 固定電話は常時留守番電話にする
- 知らない番号には出ない、折り返さない
- 電話番号は公開しない
- SNSのDMは知らない相手からは受け取らない設定にする

## 14-3. 家族ルールを1つだけ決める

たくさん決めても運用されません。1つだけにします。

> **「金の話が出たら、決める前に必ず家族に言う」**

金額の大小を問わない。相談ではなく報告でいい。これだけで、詐欺の「他言禁止」という装置が無効化されます。

高齢の親がいるなら、この1行を紙に書いて電話の横に貼っておいてください。

## 14-4. 投資の判断基準（3つだけ）

- [ ] **金融庁の登録業者一覧に載っているか**（載っていなければその時点で終了）
- [ ] **元本保証を謳っていないか**（元本保証の投資は法律上ほぼ存在しません）
- [ ] **その場で決めろと言われていないか**（急がせる時点で疑う）

この3つで、投資詐欺の大半は弾けます。

## 14-5. 契約前の10秒チェック

何かに金を払う前に、これを見てください。

- [ ] 相手の会社の登記を確認したか（法務局で誰でも取れます）
- [ ] 「必ず」「絶対」「保証」という言葉が使われていないか
- [ ] 「今日中に」と急かされていないか
- [ ] 「他言しないで」と言われていないか
- [ ] 支払方法がギフト券・暗号資産・現金手渡しになっていないか
- [ ] 相手の名前を検索したか（「〇〇 詐欺」「〇〇 評判」で検索）
- [ ] 誰かに話したか

**最後の1つがいちばん効きます。**

## 14-6. 高齢の家族を守る設計

- ATMの振込限度額を0円に設定する
- 固定電話に迷惑電話防止機能をつける（自治体が補助を出している地域があります）
- 「電話でお金の話が出たら、まず切って自分に電話して」と決めておく
- 定期的に連絡を取る（孤立が最大のリスクです）
- 通帳の記帳を一緒に見る習慣をつくる

## 14-7. 定期的にやること

- 月に1回、カード明細を全件確認する（不正利用は60日以内の届出が条件になっていることが多い）
- 半年に1回、使っていないサブスクを棚卸しする
- パスワードを使い回さない

# おわりに

伝えたいことは、突き詰めると2つです。

**1つ目。気づいた瞬間が、いちばん取り返せる可能性が高い瞬間です。** そこから先は、時間とともに可能性が下がり続けるだけ。

調べてから動く、落ち着いてから動く、明日の朝いちで動く。全部、間に合いません。詐欺側はそのタイムラグを織り込んで設計しています。だから、電話をかけながら調べる。歩きながら考える。順番を整えるより先に手を動かす。

**2つ目。金を払って解決しようとしないこと。**

相談は無料の窓口から始めてください。この記事の第7章に並べた機関は、全部タダか、それに近い金額で使えます。そして、金を払う相手は弁護士であることを名簿で確認してから決める。

焦って払った着手金が返ってきたという話を、僕はほとんど聞いたことがありません。

**初動は即断即決、支払いの判断は最低3日置く。** この2つを分けられるかどうかが、被害が1回で終わるか2回になるかを分けます。

いま被害の最中にいる人は、この記事を最後まで読まなくていいです。巻末のチェックリストの1行目から、今すぐやってください。
